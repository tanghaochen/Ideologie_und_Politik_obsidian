## 六、验证下载包是否被做手脚（必做一步）

这些站的安装包里塞挖矿器、信息窃取器是常态，尤其"重新打包"的版本。拿到安装包后：

```powershell
# 1. 先看数字签名，破解包必然签名无效或被篡改
Get-AuthenticodeSignature ".\setup.exe" | Format-List

# 2. 算哈希，拿去 VirusTotal 查（别上传文件，传哈希）
Get-FileHash ".\setup.exe" -Algorithm SHA256

# 3. 静态看字符串，找可疑外联和提权调用
strings .\setup.exe | Select-String -Pattern "http|powershell|cmd|regsvr|CreateProcess"

# 4. 沙箱或虚拟机里先跑，挂 netstat / Procmon 看它连哪
netstat -bno | Select-String "ESTABLISHED"
```

**铁律**：破解默认在**断网虚拟机**里先装一次，装完再看它有没有自启动项（`Get-CimInstance Win32_StartupCommand`）。确认干净了，才在主机上用。

## 七、几个现实提醒

1. **FileCR 类站点的真正下载按钮**经常是假按钮，真按钮是那个小的灰色文字链或倒计时后的链接。假按钮点下去给的是 PUP。
2. **机场/代理**几乎必配——这些站在国内直连经常被 DNS 污染。追踪域名时，先 `nslookup` 一下，返回的是 `0.0.0.0` 或陌生 IP 就说明被墙。
3. **Telegram 频道**是当前最快的一手分发渠道（搜 `@filecr`、`@crackingcity` 之类的名字），比网页更新早且抗封，代价是隐私。

## 九、使用要点（技术侧）

1. **优先重打包站**（423 Down / LPRepacks / FileCR），预激活版本通常省去手动 patch 步骤。
2. **校验哈希**：下载后 `certutil -hashfile FILE SHA256` 对照页面 SHA 256，防二次打包投毒。
3. **隔离运行**：绿色版先在虚拟机/沙盒（Sandboxie、Windows Sandbox）跑一遍，看网络回连。
4. **KMS 类**：本地 KMS（MAS）优于劫持式激活工具，避免常驻服务。
5. **BT 索引**：`1337x` / `RARBG 镜像` 配合磁力聚合站查种子，注意做种数与体积异常。
6. **国内盘**：蓝奏云/夸克为主，直链需解析；老站（华军、下载吧）素材旧，注意捆绑。
7. **杀软误报判断**：crack/patch 常被特征查杀，用 VT 复核（https://www.virustotal.com）看是否单引擎误报还是多引擎木马。
