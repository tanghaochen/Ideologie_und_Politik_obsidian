# 说明

### 第一层：一级衍生情绪（Primary Dyads）—— 相邻混合（间隔 0 格）

这是最容易混合、在人类日常生活中最常见的情绪组合。它们在轮盘上紧挨着彼此。图片中的灰色区域，展示的就是这第一层。

- 快乐 + 信任 = **爱 (Love)**
    
- 信任 + 恐惧 = **臣服 / 顺从 (Submission)**
    
- 恐惧 + 惊讶 = **敬畏 (Awe)**
    
- 惊讶 + 悲伤 = **失望 (Disapproval/Disappointment)**
    
- 悲伤 + 厌恶 = **悔恨 (Remorse)**
    
- 厌恶 + 愤怒 = **鄙夷 (Contempt)**
    
- 愤怒 + 期待 = **侵略 / 进取 (Aggressiveness)**
    
- 期待 + 快乐 = **乐观 (Optimism)**

### 第二层：二级衍生情绪（Secondary Dyads）—— 跨越混合（间隔 1 格）

当情绪跨越了一个花瓣进行混合时，意味着这两种情绪开始产生轻微的心理拉扯，**它们混合出的情绪往往带有更复杂的社会化属性，也更内敛。**（这也是图表上没有画出来的部分）

- 快乐 + 恐惧 = **内疚 (Guilt)** （例如：偷吃禁果的快乐，伴随害怕被发现的恐惧）
    
- 信任 + 惊讶 = **好奇 (Curiosity)** （例如：对未知事物感到惊讶，但又相信它是安全的，于是产生探索欲）
    
- 恐惧 + 悲伤 = **绝望 (Despair)** （害怕失去，同时已经感受到失去的痛苦）
    
- 惊讶 + 厌恶 = **震惊 / 愤慨 (Outrage/Unbelief)** （看到极其违背常理或恶心的事物时的反应）
    
- 悲伤 + 愤怒 = **嫉妒 (Envy)** （得不到的痛苦，加上对别人拥有的愤怒）
    
- 厌恶 + 期待 = **犬儒主义 / 愤世嫉俗 (Cynicism)** （预判了事情会很糟糕，并对此感到厌恶）
    
- 愤怒 + 快乐 = **骄傲 / 自豪 (Pride)** （通过对抗或竞争获胜后产生的快感）
    
- 期待 + 信任 = **宿命感 (Fatalism)** （对未来有预期，并完全将自己交托给信仰或命运）

### 第三层：三级衍生情绪（Tertiary Dyads）—— 远距混合（间隔 2 格）

这一层跨越了两个花瓣，两种基本情绪的跨度非常大。要将它们混合在一起，往往需要极强的外部刺激，或者深刻的心理防御机制。**这些情绪极度复杂，甚至有些矛盾。**

- 快乐 + 惊讶 = **欣喜 (Delight)** （完全没有预料到的天降横财或惊喜）
    
- 信任 + 悲伤 = **感伤 (Sentimentality)** （比如回忆起过去美好但已逝去的事物，信任过往的同时感到惋惜）
    
- 恐惧 + 厌恶 = **羞耻 (Shame)** （害怕被群体排斥，同时对自己产生自我厌恶——这是人类最难承受的情绪之一）
    
- 惊讶 + 愤怒 = **义愤 / 气愤 (Indignation)** （对突如其来的不公感到的愤怒）
    
- 悲伤 + 期待 = **悲观 (Pessimism)** （预期未来会发生事情，但笃定它是糟糕的）
    
- 厌恶 + 快乐 = **病态 / 幸灾乐祸 (Morbidity / Schadenfreude)** （看到讨厌的人倒霉，从而产生的扭曲快乐）
    
- 愤怒 + 信任 = **支配 / 控制 (Dominance)** （相信自己是对的，并用强硬的方式迫使他人服从）
    
- 期待 + 恐惧 = **焦虑 (Anxiety)** （这是现代人最常见的三级衍生：所有的注意力都在未来，同时充满惧怕）

### 第四层：对立情绪的碰撞（Opposites）—— 极点相撞（间隔 3 格 / 180 度对立）
![[image-371.png|137x146]]
轮盘上成对角线的两种情绪，属于**完全互斥（Mutually Exclusive）**。在普鲁奇克的理论中，正常情况下人类极难在同一秒钟同时体验并融合这两种情绪。 如果强行把它们挤压在一起，不会产生“衍生情绪”，而是会产生：**心理冲突（Conflict）、认知失调、或者导致其中一种情绪被潜意识压抑**。

- 快乐 vs 悲伤
    
- 信任 vs 厌恶
    
- 恐惧 vs 愤怒 （“战或逃”的拉扯，最终你只能选一个：要么恐惧退缩，要么愤怒反击）
    
- 惊讶 vs 期待 （如果你在期待某件事，你就不会惊讶；如果你惊讶了，说明它超出了期待）

如果一个人长期处于第四层对立情绪的混合状态（比如对一个人既极度信任又极度厌恶），就会导致精神上的极度内耗甚至心理疾病。

### 总结本质

普鲁奇克情绪轮盘之所以伟大，正是因为它不只停留在第一层。通过这**四个层次的“情绪调色”**，普鲁奇克把全人类成百上千种复杂、微妙、难以名状的感受，全部还原成了 8 种基本情绪的排列组合。

这也是为什么在深度的心理学研究和先进的 AI 情感模型中，必须把二级和三级衍生（比如焦虑=期待+恐惧，羞耻=恐惧+厌恶）纳入计算，才能真正读懂人类的心智。
