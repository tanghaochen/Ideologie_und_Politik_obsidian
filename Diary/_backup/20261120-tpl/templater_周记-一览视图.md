【模板使用说明 · 新建报告后请删除本节】

1. 只有一张表，不要再另开一张「自动表」。自动化只发生在**笔记列的行内查询**里。
2. 笔记列的写法：`[[YYYYMMDD]]`，后面接 `<br>` 和一个 $= 行内查询（照抄表里第 2 行那一格即可）。行内查询是**同步**的，只能读 Dataview 索引到的 `key::` 字段（`重要度` / `主题` / `人物` / `洞察` / `改进`）；`简述` / `🔍分析` / `🎯计划` / `🔮推演` 是标题下的正文，行内查询读不到，所以这几列必须人工判读。
3. **行内查询里不能出现 `|`**（`||`、`|` 都会把表格切成多列）；`??`、`?.`、`[].concat()` 都可以用。
4. **行数一变就重算 merge 坐标**：行 1 是表头、`---` 不计行号。当前模板 8 个数据行（第 2–9 行）：`A2:A3` = 周一的两行，`G2:G3` = 周一的两条笔记。单格范围（`A5:A5`）会被插件丢弃，所以只出现一行的那天不要写 merge。
5. 同一天多件事：**加行**，日期与笔记只写在第一行、其余留空并合并，不要挤进一格。
6. 字段映射：内心 ← `洞察` + `改进` + 简述里的判断；行动 ← `🎯计划` 正文 + 实际做的事；结果 ← 简述/后续日记里的数字，没有就写「尚无结果」。
7. 某天没有日记：保留一行，事件写「暂无日记记录」，其余写「暂无记录」，备注「—」，笔记只写 `—`（不要留 $= 查询，否则会显示 ★?）。
8. 格子里不要用 `##` 标题、不要用 `-` 列表符号；换行用 `<br>`；空值统一「暂无记录」。
9. 表下那句"空白格 = 与上一行同组"不要删——没装插件时靠它读表。
