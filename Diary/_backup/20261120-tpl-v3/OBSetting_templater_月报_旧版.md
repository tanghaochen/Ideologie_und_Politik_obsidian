【模板使用说明 · 新建报告后请删除本节】

1. **一张表两层合并**：
   - `周`：一周一格，覆盖该周**全部事件行**（3 件事就 3 行，1 件事就是单格、不写 merge）。
   - `事件`：一行一条，不合并。
   - `总结`：**最后一行**，`A末行:F末行` 横向合并成整行。
2. **内容列全是引用**：事件 → `[[日期#📌 事件标题|一句话]]`；行动 → `![[…#🎯 计划]]`；结果 → `![[…#📝 简述]]`。去掉 `!` 就是链接。
3. **150 字上限写在查询里，不靠 CSS**：格子里的 $= 直接 `await dv.io.load(...)` 读日记，剥掉注释 / 嵌入 / 链接 / 空字段行 / 表格行 / `#` 标题，压成一行后截到 150 字，没填显示「（本节未写）」。
   行内 JS 出现 `await` 时 Dataview 会包进 async 函数渲染返回值——**必须写 `return`**，否则格子是空的。
4. **两级标题是必须的**：一天多个 `📌` 时 `### 🎯 计划` 会重名，`[[文件#一级#二级]]` 才能定位。标题要一字不差（含 `📌 🎯 📝` 和空格）。
5. **`$=` 是同步的**：只读 `key::` 字段；`📌×n` 用 `app.metadataCache` 现数（Dataview 的 `page.file` 没有 `headings` 字段）。行内查询里不能出现 `|`，兜底用 `??`。
6. **行数一变就重算 merge**：模板现在 7 个数据行（第 2–8 行）：`A2:A3` = 第一周两行，`A5:A6` = 第三周两行，`A8:F8` = 总结行；第二周、第四周各 1 行所以不写 merge。新建后按实际行数重算。
7. 某周整周没有日记：保留一行占位（事件写「整周无日记」），周列是单格，不写 merge。
8. 周列写「第N周 + 本月覆盖的日期段」；跨月周写清只覆盖哪几天。
9. 格子里不要用 `##` 标题、不要用 `-`；换行用 `<br>`；空值统一「暂无记录」。
10. `## 月报说明` 这个标题**不要改**——年报 Excalidraw 按它嵌入本表；表下那两段说明也不要删。
