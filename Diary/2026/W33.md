### 方案二：DataviewJS 代码（排版更紧凑，推荐）

_记得在 Obsidian 设置 -> 第三方插件 -> Dataview 中开启 "Enable JavaScript Queries"。_

代码段

```dataviewjs
// 1. 修改你要汇总的时间范围（根据你的文件名格式）
const startDate = "20260810";
const endDate = "20260816";

// 2. 根据截图修正的准确路径
const folder = '"Diary/2026"'; 

let pages = dv.pages(folder)
    .where(p => p.file.name >= startDate && p.file.name <= endDate)
    .sort(p => p.file.name, 'asc');

let tableData = [];

for (let page of pages) {
    let dateLink = page.file.link;
    
    // 抓取带有 "- " 或任务勾选框的列表项
    let lists = page.file.lists.values;
    let content = "";
    
    if (lists.length > 0) {
        // 拼接抓取到的内容
        content = lists.map(l => "✔️ " + l.text).join("<br>");
    } else {
        content = "*(本日无记录或未转换为列表格式)*";
    }
    
    tableData.push([dateLink, content]);
}

dv.table(["日期", "每日复盘记录"], tableData);
```
