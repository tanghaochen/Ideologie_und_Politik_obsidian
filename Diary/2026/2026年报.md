# 2026 年报

> **模板说明**：`OBSetting/templater` 中目前只有 `日记-事件模板` 与 `周记-一览视图`，**不存在月报和年报模板**。本文件沿用这两个模板共同的字段体系（重要度 / 主题 / 简述 / 分析 / 计划 / 推演）做年度汇总，并在文末说明与模板缺失有关的取舍。
>
> **数据来源**：`Diary/2026` 下的日记（原始记录）与 `M04`～`M11` 月报。本文件不新增任何未经记录的事实；无法判断的地方直接写"暂无记录"。

## 一、本年数据概览

```dataviewjs
const folder = "Diary/2026";
const pages = dv.pages(`"${folder}"`).where(p => /^2026\d{4}/.test(p.file.name)).sort(p => p.file.name);
let events = 0, empty = 0, months = {};
for (const p of pages) {
  const raw = await dv.io.load(p.file.path);
  const n = (raw.match(/^## 📌/gm) || []).length;
  events += n;
  if (!n) empty++;
  const m = +p.file.name.slice(4, 6);
  months[m] = (months[m] || 0) + n;
}
const withData = Object.keys(months).filter(m => months[m] > 0).sort((a, b) => a - b);
dv.paragraph(
  `- 日记文件：**${pages.length}** 篇（其中 **${empty}** 篇无事件级内容）\n` +
  `- 事件总数：**${events}** 件\n` +
  `- 有记录的月份：**${withData.map(m => m + "月(" + months[m] + ")").join("、") || "暂无"}**\n` +
  `- 无有效记录的月份：${[1,2,3,6,7,12].filter(m => !months[m]).map(m => m + "月").join("、")}`
);
```

## 三、12 个月：内心 / 行动 / 结果

> **自动化程度说明**：下表由 DataviewJS 读取 `Diary/2026` 的原始事件自动生成，每个月固定一行，未来新增日记会自动更新。
>
> 字段映射依据现有模板的字段体系，而不是凭猜测：
>
> - **内心** ← 事件的 `洞察` / `改进` 字段（认知与心理层面的内容）
> - **行动** ← 事件标题（模板中标题即"做了什么"）
> - **结果** ← 从 `简述` 与 `洞察` 中抽取可验证的数字（小时 / 元 / 分 / 分数），没有数字就写"暂无记录"
>
> 日记模板本身没有 `结果` 字段，因此结果列是"从正文抽取可验证数据"，不是人工填写的判断。

```dataviewjs
// ═══════════ 年报 12 个月 · 内心 / 行动 / 结果 ═══════════
const folder = "Diary/2026";
const YEAR = "2026";
const MAX_INNER = 2, MAX_ACT = 3, MAX_RES = 3, CUT = 44;

const esc = s => String(s).replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;");
const cut = (s, n) => !s ? "" : (s.length > n ? s.slice(0, n) + "…" : s);
const alink = (l, t) => `<a href="${l.path}" data-href="${l.path}" class="internal-link">${esc(t)}</a>`;

function parseDiary(raw, page) {
  const content = String(raw).replace(/%%[\s\S]*?%%/g, "").replace(/<!--[\s\S]*?-->/g, "");
  const out = [];
  const blocks = content.split(/^## 📌\s*/m).slice(1);
  for (const b of blocks) {
    const lines = b.split("\n");
    const ev = { title: lines[0].trim(), date: page.file.name, link: page.file.link, fields: {}, free: {} };
    let section = null;
    for (const line of lines.slice(1)) {
      const h = line.match(/^###\s*(.+)/);
      if (h) { section = h[1].replace(/[^\u4e00-\u9fa5A-Za-z]/g, ""); continue; }
      if (/^#{1,2}\s/.test(line)) continue;
      const f = line.match(/^\s*-?\s*([\w\u4e00-\u9fa5]+)::\s*(.*)$/);
      if (f) { if (f[2].trim()) ev.fields[f[1]] = f[2].trim(); continue; }
      if (section && line.trim()) ev.free[section] = (ev.free[section] || "") + line.trim() + " ";
    }
    out.push(ev);
  }
  return out;
}

const byMonth = {};
for (let m = 1; m <= 12; m++) byMonth[m] = [];
for (const p of dv.pages(`"${folder}"`).where(p => new RegExp("^" + YEAR + "\\d{4}").test(p.file.name)).sort(p => p.file.name)) {
  const evs = parseDiary(await dv.io.load(p.file.path), p);
  const m = +p.file.name.slice(4, 6);
  if (m >= 1 && m <= 12) byMonth[m].push(...evs);
}

const NUM = /(\d+\s*\/\s*100|\d+(?:\.\d+)?\s*个?\s*(?:小时|分钟|元))/g;
const rows = [];
for (let m = 1; m <= 12; m++) {
  const evs = byMonth[m];
  if (!evs.length) { rows.push([m + "月", '<span style="opacity:.4">暂无记录</span>', '<span style="opacity:.4">暂无记录</span>', '<span style="opacity:.4">暂无记录</span>']); continue; }

  const inner = [];
  for (const e of evs) {
    for (const k of ["洞察", "改进"]) {
      const v = e.fields[k];
      if (v && !inner.some(x => x.startsWith(v.slice(0, 8)))) inner.push(v);
    }
  }
  const innerCell = inner.slice(0, MAX_INNER).map((v, i) =>
    `<div>${esc(cut(v, CUT))}${i === 0 ? "" : ""}</div>`).join("") || '<span style="opacity:.4">暂无记录</span>';

  const actCell = evs.slice(0, MAX_ACT).map(e =>
    `<div>${e.date.slice(6, 8)}日 ${alink(e.link, cut(e.title, 18))}</div>`).join("")
    + (evs.length > MAX_ACT ? `<div style="opacity:.6">…共 ${evs.length} 件</div>` : "");

  const seen = new Set(); const res = [];
  for (const e of evs) {
    const blob = (e.free["简述"] || "") + " " + Object.values(e.fields).join(" ");
    for (const hit of (blob.match(NUM) || [])) {
      const v = hit.replace(/\s+/g, "");
      if (!seen.has(v)) { seen.add(v); res.push(v); }
      if (res.length >= MAX_RES) break;
    }
    if (res.length >= MAX_RES) break;
  }
  const resCell = res.length
    ? res.map(v => `<span style="display:inline-block;border:1px dashed var(--text-muted);border-radius:6px;padding:0 6px;margin:1px 3px 1px 0;font-size:.9em">${esc(v)}</span>`).join("")
    : '<span style="opacity:.4">暂无记录</span>';

  rows.push([m + "月", innerCell, actCell, resCell]);
}

const css = `
  table.yb{width:100%;border-collapse:collapse;table-layout:fixed;margin-top:10px}
  table.yb th,table.yb td{border:1px solid var(--background-modifier-border);padding:6px 8px;
    vertical-align:top;font-size:.88em;line-height:1.5;white-space:normal!important;
    word-break:break-word!important;overflow-wrap:anywhere!important}
  table.yb th{background:var(--background-secondary)}
  table.yb td:first-child{font-weight:bold;text-align:center;width:8%}
`;

let html = `<style>${css}</style><table class="yb"><thead><tr><th>月份</th><th style="width:31%">内心</th><th style="width:28%">行动</th><th style="width:33%">结果</th></tr></thead><tbody>`;
for (const r of rows) html += `<tr><td>${r[0]}</td><td>${r[1]}</td><td>${r[2]}</td><td>${r[3]}</td></tr>`;
html += "</tbody></table>";

const wrap = document.createElement("div");
wrap.innerHTML = html;
dv.container.appendChild(wrap);
```

### 关于这张表的三个限制（必须说明）

1. **DataviewJS 生成的表格不是 Markdown 源码表格**。它的单元格无法直接双击编辑，也不参与 Obsidian 的表格格式化。要改内容，必须改原始日记（这是设计上的取舍：日记是唯一数据源）。
2. **Arrows 连线无法在 DataviewJS 输出中生效**。Arrows 插件是在 Markdown 渲染层扫描 `{id}` 标记并画线的，动态插入的 HTML 不在它的扫描范围内。因此本文第二节的事件链连线全部写在**原生 Markdown 段落**里，表格内不放连线标记。
3. **结果列是"抽取"不是"判定"**。它只显示正文里出现过的数字（小时 / 元 / 分 / 分数），不能替你判断"是否达到预期"；判断写在第四节与第五节。

## 四、德语学习年度轨迹

- **写作**：4 月单句与短作文（B1 水平，五类机械错误）→ 5 月整段对话与写作（暴露被动语态、代词性别、虚拟式）→ 9 月作文开始写自己的作息 → 11 月进入 Goethe B2 题型（投诉邮件 52/100、SMS + E-Mail 26/100）。
- **阅读/精读**：4 月 A1 复习到第 15 节；9/29 重构精读流程（中文反译回德语 + 复听），称"效果大幅提升"，这是全年唯一一次方法层面的突破。
- **持续未解决的错误**：① 英语词干扰（5 月的 and / so lang → 11 月的 commen / Find / detail）；② 动词变位与语序（贯穿 4 月、5 月、11 月）；③ 名词词性与格（4 月、11 月）。
- **无法评估的部分**：全年没有词汇量记录、没有听力分数、没有阅读速度数据，也没有任何一次完整的模考成绩（只有 11 月两次写作单项批改）。因此**不能用"背了多少单词"或"学了多少小时"推出语言能力**。
