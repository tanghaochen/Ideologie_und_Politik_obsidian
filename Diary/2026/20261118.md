###### 第 1 句

① 💬 本句原意
> 💬 本句原意：你好，我是 Kai。

② 📝 原文批注

Hallo! <del><span style="color:#c00000">ich</span></del><sup>1</sup> bin Kai<mark>，</mark><sup>2</sup> <span style="color:#8a8a00">（对朋友自报姓名，语境多余）</span><sup>3</sup>

**得分：6/10**

📝 逐处拆解（分行缩进）：
- ¹ ich → **Ich**
- ² `,` → `.`
- ³ *Ich bin Kai* → 可直接删除，改为称呼 *Hallo Ekaterini,*

③ 📋 本句问题一览（含错误原因解释）

- ¹ 🔴 大小写错误：*ich* → *Ich*
  - 🩺 原因：*Hallo!* 已经是一个带感叹号的完整句子，之后即为**新句开头**，德语规定所有句首单词（含代词）首字母大写。
- ² 🔴 逗号连接两个主句（Kommaspleiß）：*Kai,* → *Kai.*
  - 🩺 原因：德语两个独立主句之间**不能只用逗号相连**，必须用句号断开，或用 *und / denn / aber* 等并列连词。逗号只用于从句、列举、同位语。
- ³ 🟡 语用不当：*Ich bin Kai*
  - 🩺 原因：收信人是你的朋友 Ekaterini，她知道你是谁。德语私人短信的开头是**称呼**（*Hallo Ekaterini, / Liebe Ekaterini,*），不是自我介绍；自我介绍只用于陌生对象。考官在这一项上评的是"称呼是否得体"。

④ 🔍 原文直译对照

🔍 本句直译（按你实际写的德语）：
「你好！我 是 Kai，我的女朋友 我 很少 事故 出现……」

⚠️ 注意：你用一个逗号把"我是 Kai"和后面的长句粘在了一起，直译出来是一口气读不完的病句。如果你只想表达"你好，我是 Kai"，应该写 *Hallo! Ich bin Kai.*

⑤ 🔬 本句重写示范（同一原意 × 两种写法）

- 🛡️ **最小化改写**：Hallo! Ich bin Kai.
- 🚀 **高级改写**：Hallo Ekaterini, hier schreibt Kai – entschuldige, dass ich mich erst jetzt melde.（*sich melden* 是短信/邮件场景固定动词；*dass* 从句作 *entschuldige* 的说明成分，B2 高频句式）

###### 第 2 句

① 💬 本句原意
> 💬 本句原意：我的女朋友出了个小事故，因为我妈妈生病了，我得照顾她。

② 📝 原文批注

Meine Freundin <del><span style="color:#c00000">habe ich</span></del><sup>1</sup> <del><span style="color:#c00000">wenig Unfäll</span></del><sup>2</sup> <mark>erscheinen</mark><sup>3</sup>, <mark>beim</mark><sup>4</sup> <del><span style="color:#c00000">meiner Mutter Kranken</span></del><sup>5</sup> ist und ich <del><span style="color:#c00000">ihr pfelege</span></del><sup>6</sup> muss.

**得分：2/10**

📝 逐处拆解（分行缩进）：
- ¹ *habe ich* → **hatte / hat gehabt**
- ² *wenig Unfäll* → **einen kleinen Unfall**
- ³ *erscheinen* → **gehabt**（或删除，改用 *hatte einen Unfall*）
- ⁴ *beim* → **weil**
- ⁵ *meiner Mutter Kranken* → **meine Mutter krank**
- ⁶ *ihr pfelege* → **sie pflegen**

③ 📋 本句问题一览（含错误原因解释）

- ¹ 🔴 主语与动词不匹配 + 语序错误：*Meine Freundin habe ich* → *Meine Freundin hatte*
  - 🩺 原因：句子主语是 *Meine Freundin*（第三人称单数），变位动词必须是 *hat/hatte*；你多写了一个 *ich*，导致动词按第一人称变位，主语和谓语完全脱节。
- ² 🔴 冠词、数、格、形容词变格四重错误：*wenig Unfäll* → *einen kleinen Unfall*
  - 🩺 原因：① *Unfall* 是可数名词，单数须带冠词；② 这里是 *haben* 的第四格宾语，阳性单数用 *einen*；③ 形容词在不定冠词后弱变化为 *kleinen*；④ *Unfall* 的复数才是 *Unfälle*，不能自行加 *-ll* 变音。
- ³ 🔴 动词词义错误：*erscheinen* → *gehabt / passiert*
  - 🩺 原因：*erscheinen* 意为"出现、显得"（如 *Er erscheint pünktlich*），**不能**表示"发生事故"。德语说 *einen Unfall haben / einen Unfall gehabt haben* 或 *Ein Unfall ist passiert*。
- ⁴ 🔴 从句连词错误：*beim* → *weil*
  - 🩺 原因：*beim* 是 *bei + dem* 的缩合介词，后面只能接名词（*beim Arzt*），**不能引导从句**。表达原因必须用从属连词 *weil / da*。
- ⁵ 🔴 形容词被误当名词 + 格错误：*meiner Mutter Kranken* → *meine Mutter krank*
  - 🩺 原因：*krank* 是形容词，作表语时不带冠词、不变格、不大写；*meine Mutter* 作从句主语用第一格，不是第三格 *meiner*。
- ⁶ 🔴 人称代词格错误 + 形式错误：*ihr pfelege* → *sie pflegen*
  - 🩺 原因：① *pflegen* 的宾语是第四格，指代 *die Mutter* 须用 *sie*（*ihr* 是第三格，且只用于"给她"）；② 从句中情态动词 *muss* 已占句末，实义动词必须还原为**不定式** *pflegen*，不能变位成 *pfelege*；③ 拼写为 *pflegen*（*pf* + *legen*），不是 *pfelegen*。

④ 🔍 原文直译对照

🔍 本句直译（按你实际写的德语）：
「我的女朋友 我 有 很少 事故 出现，在……的时候 我的母亲 病人 是 并且 我 她(第三格) 照顾 必须。」

⚠️ 注意：以下两点严重偏离你原本的意思：
- *habe ich* 把主语换成了"我"，读者会以为"我的女朋友，我把（她）……出现了"——主谓错位让句子无法解读；你想表达"她出了事故"，应写 *Meine Freundin hatte einen Unfall.*
- *beim* 引出的不是原因从句，读者会以为你在描述"在妈妈生病的时候"这个时间点，而你实际想说的是因果关系；应写 *weil meine Mutter krank ist*.

⑤ 🔬 本句重写示范（同一原意 × 两种写法）

- 🛡️ **最小化改写**：Meine Freundin hatte einen kleinen Unfall, und meine Mutter ist krank – ich muss sie pflegen.
- 🚀 **高级改写**：Leider hatte meine Freundin einen kleinen Unfall, und weil meine Mutter krank ist, muss ich sie zu Hause pflegen.（*weil* 从句置于句首占第一位置，主句动词 *muss* 必须紧跟其后占第二位置——这是 B2 必考的"从句 + 主句"倒装结构）

###### 第 3 句

① 💬 本句原意
> 💬 本句原意：我非常抱歉。

② 📝 原文批注

Ich <mark>viel</mark><sup>1</sup> <del><span style="color:#c00000">Entschuldigung</span></del><sup>2</sup> <span style="color:#0a7d0a; font-weight:bold">（道歉意识 ✅ 有礼貌，方向对）</span>.

**得分：2/10**

📝 逐处拆解（分行缩进）：
- ¹ *viel* → **vielmals / sehr**
- ² *Entschuldigung* → **entschuldige mich**（动词化）

③ 📋 本句问题一览（含错误原因解释）

- ¹ 🔴 **全句没有谓语动词**：*Ich viel Entschuldigung* → *Ich entschuldige mich vielmals.*
  - 🩺 原因：你只写了主语 *Ich* + 副词 *viel* + 名词 *Entschuldigung*，德语主句**必须有变位动词占第二位**。*Entschuldigung* 是名词，不能充当谓语，须换成动词 *sich entschuldigen*。
- ² 🟡 副词选择不当：*viel* → *vielmals / sehr*
  - 🩺 原因：*viel* 修饰的是不可数名词（*viel Zeit, viel Geld*）；修饰动词表示"多次/非常"要用 *vielmals*，修饰形容词或情感用 *sehr*（*Es tut mir sehr leid*）。

④ 🔍 原文直译对照

🔍 本句直译（按你实际写的德语）：
「我 很多 道歉（名词）。」

⚠️ 注意：这句直译出来是"我一堆道歉"，像名词堆砌，德语读者会等你把动词说完。你想表达"我很抱歉"，应写 *Ich entschuldige mich vielmals.* 或 *Es tut mir sehr leid.*

⑤ 🔬 本句重写示范（同一原意 × 两种写法）

- 🛡️ **最小化改写**：Ich entschuldige mich vielmals.
- 🚀 **高级改写**：Das tut mir wirklich sehr leid – bitte entschuldige die Unannehmlichkeiten.（*die Unannehmlichkeiten* 是 B2 道歉万能名物化搭配，比 *Entschuldigung* 更书面）

###### 第 4 句

① 💬 本句原意
> 💬 本句原意：所以我会晚一点到，我需要（大约）两天时间；新的见面地点和时间是……

② 📝 原文批注

<mark>Sodass</mark><sup>1</sup> ich später <mark>kommen</mark><sup>2</sup>, <del><span style="color:#c00000">brauchet</span></del><sup>3</sup> die Zeit <del><span style="color:#c00000">zwei Tagen</span></del><sup>4</sup>. <mark>（缺：neuer Ort + neue Uhrzeit）</mark><sup>5</sup>

**得分：2/10**

📝 逐处拆解（分行缩进）：
- ¹ *Sodass …* → **Deshalb …**（主句语序）
- ² *kommen* → **komme**（*Deshalb komme ich später.*）
- ³ *brauchet* → **brauche**
- ⁴ *die Zeit zwei Tagen* → **zwei Stunden / zwei Tage Zeit**
- ⁵ 缺第三个任务点：**neuer Ort + neue Uhrzeit**

③ 📋 本句问题一览（含错误原因解释）

- ¹ 🔴 连词误用 + 从句语序缺失：*Sodass ich später kommen* → *Deshalb komme ich später*
  - 🩺 原因：*sodass* 是引导**结果从句**的从属连词，一旦使用，变位动词必须搬到句末（*…, sodass ich später komme*）；而且 *sodass* 通常不放在句首开启新句。表达"所以"并开启主句时，应用副词 *Deshalb / Daher*，此时**动词占第二位、主语紧随其后**。
- ² 🔴 变位动词缺失（不定式当谓语）：*kommen* → *komme*
  - 🩺 原因：*ich* 作主语时现在时变位为 *komme*；*kommen* 是不定式，只能在情态动词或 *zu* 之后出现在句末。
- ³ 🔴 动词变位错误：*brauchet* → *brauche*
  - 🩺 原因：*brauchen* 第一人称单数为 *brauche*；*-et* 是 *ihr* 或旧式第三人称单数的词尾，此处人称不符。
- ⁴ 🔴 名词格与数量表达错误：*die Zeit zwei Tagen* → *zwei Tage Zeit / zwei Stunden*
  - 🩺 原因：① 德语数量表达是"**数量 + 名词 + Zeit**"（*zwei Tage Zeit*），不是"die Zeit zwei …"；② *Tagen* 是第三格复数，此处需第四格复数 *Tage*；③ 更关键的是逻辑上"晚到"通常以小时计（*zwei Stunden*），"两天"在短信约会语境中不合常理。
- ⁵ 🔴 **任务点缺失（Aufgabenerfüllung）**：缺 *neuer Ort + neue Uhrzeit*
  - 🩺 原因：Teil 1 明确要求"为见面提出一个新地点和新时间"。歌德评分第一条就是"是否写全三个要点"，缺一点直接扣分，且这是**最容易拿的分**。补法：*Treffen wir uns um 18 Uhr vor dem Kino?*

④ 🔍 原文直译对照

🔍 本句直译（按你实际写的德语）：
「以便 我 更晚 来，需要（他/她？） 这 时间 两 天（第三格）。」

⚠️ 注意：以下两处偏离：
- *Sodass … kommen* 缺变位动词，直译成"以便我更晚来"后面没有主句，句子悬空；你想说"所以我会晚到"，应写 *Deshalb komme ich später.*
- *brauchet die Zeit zwei Tagen* 无法确定主语（是"我"还是"他"），且"这时间两天"不成句；你想说"我需要两个小时"，应写 *Ich brauche zwei Stunden.*

⑤ 🔬 本句重写示范（同一原意 × 两种写法）

- 🛡️ **最小化改写**：Deshalb komme ich später – ich brauche zwei Stunden. Treffen wir uns um 18 Uhr vor dem Kino?
- 🚀 **高级改写**：Leider schaffe ich es nicht pünktlich, ich brauche noch etwa zwei Stunden. Könnten wir uns stattdessen um 18 Uhr am Bahnhof treffen?（*es nicht pünktlich schaffen* 是口语高级表达；*Könnten wir …?* 用第二虚拟式提出委婉建议，是 B2 加分点，同时补齐了第三个任务点）

###### Teil 2 —— E-Mail an Herrn Lehmann

###### 第 5 句

① 💬 本句原意
> 💬 本句原意：尊敬的 Lehmann 先生：

② 📝 原文批注

<del><span style="color:#c00000">Sehe</span></del><sup>1</sup> geehrter <del><span style="color:#c00000">Harr</span></del><sup>2</sup> <del><span style="color:#c00000">Lehman</span></del><sup>3</sup>, <span style="color:#0a7d0a; font-weight:bold">（✅ 正式称呼的位置和 *geehrter* 的变格完全正确，这是 B2 邮件的第一分）</span>

**得分：4/10**

📝 逐处拆解（分行缩进）：
- ¹ *Sehe* → **Sehr**
- ² *Harr* → **Herr**
- ³ *Lehman* → **Lehmann**

③ 📋 本句问题一览（含错误原因解释）

- ¹ 🔴 拼写/词性混淆：*Sehe* → *Sehr*
  - 🩺 原因：*sehe* 是动词 *sehen* 的第一人称变位（"我看"），而这里需要的是副词 *sehr*（"非常"）修饰 *geehrter*。两者发音接近但词性完全不同，属高频听写型错误。
- ² 🔴 拼写：*Harr* → *Herr*
  - 🩺 原因：*Herr* 只有一个 *r* 加词尾 *-n*；双写 *rr* 在德语中只出现在 *Herr* 之外的少数词（如 *irren*），此处属拼写错误。
- ³ 🔴 专名抄写错误：*Lehman* → *Lehmann*
  - 🩺 原因：题目明确给出 *Herr Lehmann*，德语姓氏的双写 *nn* 不能简化。**抄写题干人名是零成本得分点，必须逐字核对。**

- ¹ *anderin* → **einen anderen**
- ² *freunde* → **Freund**
- ³ *möche* → **möchte**
- ⁴ `,` → `.`
- ⁵ *Find* → **den Weg finden / zeigen**

- ¹ 🔴 形容词变格错误：*anderin* → *einen anderen*
  - 🩺 原因：*ander-* 作形容词在不定冠词 *einen* 后、阳性第四格，词尾必须是 **-en**（*einen anderen Freund*）；*anderin* 是拼写 + 词尾双重错误。

##### 模块三：写作思路升维（Inhaltliche Erweiterung）

💡 **逻辑链条识别（先诊断再缝合）**

##### 模块四：写作方法论指导（Methodik）

💡 **本期核心方法：动词括号法（Satzklammer）——"数动词"三步自检**

你的错误里有 **6 处**属于同一类：动词没站对位置。以后每写完一句，做 3 步：

1. **数动词**：找出句子里所有动词。有几个？
2. **定位置**：
   - 主句 → 变位动词语**第二位**（*Deshalb **komme** ich später.*）
   - 情态动词出现 → 变位情态动词第二位，**不定式踢到句末**（*Ich **möchte** einen Freund mitbringen.*）
   - *weil / dass / obwohl* 从句 → 变位动词**搬到句末**（*…, weil meine Mutter krank **ist***）
3. **验括号**：动词是否形成"左半 + 右半"的括号，把其余成分夹在中间？

**现场演示你的句子：**
- ❌ *Ich habe anderin freunde und möche mitbringen* → 数出 2 个动词，但 *möchte* 变位错、*mitbringen* 未归位。
- ✅ *Ich **möchte** gerne einen Freund **mitbringen**.* → 左半 *möchte* 第二位，右半 *mitbringen* 句末，括号闭合。

> 1. commen → **kommen**（动词，不定式）
> 2. Find → **finden / zeigen**（动词，须置于句末）
> 3. detail → **genau**（形容词，需按格变尾）
> （解析：英语拼写在德语作文中一律按"无法理解"处理，必须建立"英语词 → 德语词"的替换反射。）
