# 德语 B 2｜描述物品的摆放：位置、姿态与排列

> 承接上一主题：上节课解决“物品**长什么样**”，这节课解决“物品**在哪里、怎么摆**”。两者合起来，就是完整的 *Gegenstandsund Raumbeschreibung*——歌德 B 2 口语（图片/场景描述）与写作（房间、展厅、橱窗、失物现场）的共同基础。

---

## 一、学习目标与知识地图

学完本主题，你应当能：

1. **定位**：用介词短语准确说明任一物品相对于参照物的位置，并选对格（Dativ）。
2. **选动词**：区分 *stehen / liegen / hängen / stecken / sitzen* 五类姿态动词——这是德语描述摆放时**最核心的母语差异点**。
3. **换视角**：从“入口视角”出发，按固定路线连续描述一个空间，句与句之间有推进，而非罗列。
4. **写整段**：写 150–200 词的场景描述，含空间层次、排列关系与一句评价。

```mermaid
知识依赖链：
位置介词(Dativ) ─┐
姿态动词 ────────┼→ 定位句 → 语序(地点前置) → 排列关系词 → 成段描述
方位副词 ────────┘
```

**核心命题**：本主题不是“多背几个介词”。真正的难点是两个德语特有的机制：

- **机制 A：静态与动态的介词格对立**（*auf dem Tisch* vs *auf den Tisch*）+ **动词配对**（*liegen/legen*）。
- **机制 B：姿态动词强制区分朝向**（德语必须说书“躺着”、瓶子“站着”，中文的“在”无法对应）。

### 系统 2｜方位介词（回答 Wo? → Dativ）

| 介词 | 含义 | 例句 |
|---|---|---|
| **in** (+D) | 在……内部/空间内 | in der Schublade, in der Ecke, in der Mitte |
| **an** (+D) | 贴靠（垂直面、边缘、界线） | an der Wand, an der Decke, am Fenster, am Rand |
| **auf** (+D) | 在……上表面 | auf dem Tisch, auf dem Regal, auf dem Boden |
| **über** (+D) | 在……上方（不接触） | über dem Sofa |
| **unter** (+D) | 在……下方 | unter dem Bett |
| **vor** (+D) | 在……前面 | vor dem Fenster |
| **hinter** (+D) | 在……后面 | hinter der Tür |
| **neben** (+D) | 在……旁边 | neben dem Bett |
| **zwischen** (+D) | 在……之间 | zwischen dem Regal und der Tür |
| **gegenüber** (+D) | 在……对面 | dem Eingang gegenüber |

**扩展（B 2 加分，注意格）**：

- + Dativ：**außerhalb / innerhalb**（也可 + Genitiv）、**mitten in / mitten auf**
- + Genitiv：**oberhalb, unterhalb, links/rechts** 用 *von* + D、**diesseits / jenseits, statt …**
- + Akkusativ：**um … herum**（*um den Tisch herum*）、**entlang**（后置：*die Straße entlang*）
- 相对方位：**links von / rechts von** + D（*links vom Fenster*）

> ⚠️ 介词选择的判断逻辑（详见第四节）：
> **in** = 容器/封闭空间；**auf** = 水平上表面；**an** = 垂直面或边界接触。

## 三、第二层：核心机制——静态/动态与姿态动词

### 机制 A：Wechselpräpositionen 的格对立

|     | 静态：**Wo?** → **Dativ**                  | 动态：**Wohin?** → **Akkusativ**            |
| --- | --------------------------------------- | ---------------------------------------- |
| 介词  | auf **dem** Tisch                       | auf **den** Tisch                        |
| 动词  | liegen, stehen, hängen, sitzen, stecken | legen, stellen, hängen, setzen, stecken  |
| 例句  | Das Buch **liegt** auf **dem** Tisch.   | Ich **lege** das Buch auf **den** Tisch. |
| 语义  | 状态：书在桌上                                 | 动作：把书放到桌上                                |

**判断方法**：问自己 —— 这句话是**在描述一个已经存在的画面**（Wo?），还是**在说一个把东西挪过去的行为**（Wohin?）？描述摆放时 90% 是 Wo?，用 Dativ。

**动词配对表**（必须成对记）：

| 状态（Dativ） | 动作（Akkusativ） | 适用对象 |
|---|---|---|
| **stehen** – stand – gestanden | **stellen** – stellte – gestellt | 竖立、有底座的：瓶、柜、椅、桌、人 |
| **liegen** – lag – gelegen | **legen** – legte – gelegt | 平放躺倒的：书、纸、地毯、钥匙 |
| **hängen** – hing – gehangen | **hängen** – hängte – gehängt | 悬挂的：画、衣、灯 |
| **sitzen** – saß – gesessen | **setzen** – setzte – gesetzt | 嵌入、贴合：纽扣、盖子、人 |
| **stecken** – steckte – gesteckt | **stecken**（同形） | 插入物：钥匙、插头、信 |

> ⚠️ **hängen 的特殊性**：现在时三单都是 *hängt*，只有过去时和完成时区分：
> - 状态：Das Bild **hing** an der Wand. / Es **hat** an der Wand **gehangen**.
> - 动作：Ich **hängte** das Bild an die Wand. / Ich **habe** es **angehängt**.
> 这是 B 2 考试中极易出错的一处。

### 机制 B：姿态动词的选择逻辑

德语**强制**在描述位置时表达物体的“姿态”。中文说“桌上有个瓶子/书”，德语必须二选一：

| 判断依据 | 用 stehen | 用 liegen |
|---|---|---|
| 垂直轴突出、有底座 | 瓶、杯、柜、椅、人、铅笔（竖着） | — |
| 水平面突出 | — | 书、纸、地毯、钥匙、手机、餐具（平放） |
| 悬挂 | hängen | — |
| 插入/嵌入 | stecken / sitzen | — |

对照练习（同一位置，不同姿态）：

> Auf dem Tisch **steht** eine Flasche. （瓶）
> Auf dem Tisch **liegt** ein Löffel. （勺）
> Auf dem Tisch **liegt** ein Buch, **daneben steht** eine Tasse.
> An der Wand **hängt** ein Kalender.
> Im Schloss **steckt** ein Schlüssel.
> Der Knopf **sitzt** am Kragen.

**边界说明**：这是德语的习惯性分类，不是物理定律。圆盘类（*Teller*）通常 *steht*（竖放或叠放时），平放的大件（*Teppich*）用 *liegen*；个别物体允许两种说法，语义略有差别（*Die Flasche liegt im Kühlschrank* 强调横放）。词典与语感比规则更可靠。

### 机制 C：状态被动的替代说法（正式书面语）

描述陈列、布置时，除 *stehen/liegen* 外，还可用 **Zustandspassiv**（sein + 第二分词），语域更正式：

| 表达 | 例句 |
|---|---|
| aufgestellt sein | Die Stühle **sind** um den Tisch **aufgestellt**. |
| aufgehängt sein | Die Bilder **sind** in einer Reihe **aufgehängt**. |
| angebracht sein | An der Tür **ist** ein Schild **angebracht**. |
| angeordnet sein | Die Stühle **sind** kreisförmig **angeordnet**. |
| verteilt sein | Die Tische **sind** gleichmäßig im Raum **verteilt**. |

## 四、第三层：介词选择的判断路径

```mermaid
目标物与参照物的关系？
├─ 在参照物内部 / 封闭空间里 → in + Dativ
│    in der Schublade, im Regal, in der Ecke, in der Mitte, im Kühlschrank
├─ 落在水平上表面上 → auf + Dativ
│    auf dem Tisch, auf dem Regal(=顶上), auf dem Boden, auf der Theke
├─ 贴靠垂直面 / 边界 / 条状位置 → an + Dativ
│    an der Wand, an der Decke, an der Tür, am Fenster, am Rand, am Eingang
├─ 有间隔的上下 / 前后 / 左右 → über / unter / vor / hinter / neben + Dativ
└─ 两物之间 → zwischen + Dativ（复数名词加 -n：zwischen den Stühlen）
```

**两处高频混淆**：

| 对比 | 差别 |
|---|---|
| **im** Regal / **auf dem** Regal | 格层里面 / 架子顶上 |
| **an der** Wand / **auf** der Wand | 挂在墙上 / 贴在墙面上（如墙贴） |
| **am** Fenster / **vor dem** Fenster | 窗边（窗台、窗前站）/ 窗外的前方 |
| **in der** Ecke / **an der** Ecke | 房间角落内 / 街道拐角处 |

## 五、第四层：语序——"地点在前，物品在后"

描述摆放时，最有力的句式调整是把**地点放到句首**（Vorfeld），把新信息（物品）推到句末：

| 语序 | 例句 | 效果 |
|---|---|---|
| 中性 | Ein Sofa steht an der Wand. | 陈述单一事实 |
| **地点前置** | **An der Wand steht** ein Sofa. | 画面感强，适合连续描述 |
| es-句式 | **Es steht** ein Sofa an der Wand. | 引出新对象 |
| 存在句 | **Es gibt** ein Sofa an der Wand. | 强调"有"，不强调姿态 |

**规则**：地点前置后，动词必须占第二位，主语移到动词后 → 倒装。这是整套描述的地基句式。

**其他定位句式**：

| 句型 | 例句 | 语域 |
|---|---|---|
| sich befinden | In der Ecke **befindet sich** ein Sessel. | 正式、书面 |
| zu sehen sein | Am Eingang **ist** ein Schild **zu sehen**. | 描写可见物 |
| sich erstrecken | Das Regal **erstreckt sich** über die ganze Wand. | 强调延伸 |
| umgeben / säumen | Bäume **säumen** den Weg. | 文学性 |

## 六、第五层：排列关系词（Anordnung）

描述“摆放”不只讲单点位置，还要讲**物体之间的相对秩序**——这是 A 2 到 B 2 的分水岭。

| 类别 | 表达 | 例句 |
|---|---|---|
| 成行 | in einer Reihe, aufgereiht | Die Stühle stehen **in einer Reihe** an der Wand. |
| 并排 | nebeneinander | Die Gläser stehen **nebeneinander** im Schrank. |
| 叠放 | übereinander, gestapelt | Die Kartons sind **übereinander gestapelt**. |
| 前后 | hintereinander | Die Autos parken **hintereinander**. |
| 环绕 | um … herum, im Kreis | Die Stühle stehen **um den Tisch herum**. |
| 对称 | symmetrisch, gegenüberliegend | Die Lampen hängen **symmetrisch** zur Mitte. |
| 分散 | verstreut, verteilt | Auf dem Boden liegen **verstreut** einige Bücher. |
| 密集 | dicht an dicht, lückenlos | Die Bücher stehen **dicht an dicht**. |
| 有序/无序 | ordentlich, aufgeräumt / unordentlich, chaotisch | Im Regal ist alles **ordentlich** sortiert. |
| 距离 | direkt an, unmittelbar neben, mit etwas Abstand zu | Der Stuhl steht **direkt an** der Wand. |

## 七、第六层：成段策略——从入口开始的四条规则

写一整段场景描述，遵循"**从大到小、固定视角、逐句推进**"：

| 步骤 | 内容 | 语言手段 |
|---|---|---|
| ① 建立视角 | 从门口/画面外看 | *Wenn man … betritt, … / Vom Eingang aus gesehen …* |
| ② 大件与固定结构 | 墙、窗、门、大型家具 | *An der linken Wand … / Gegenüber …* |
| ③ 中件 | 桌面、墙面、柜台上的物品 | *Darauf … / Über dem Tisch …* |
| ④ 细节与排列 | 小物、秩序、数量 | *in einer Reihe / verstreut / dicht an dicht* |
| ⑤ 整体印象 | 一句评价 | *Insgesamt wirkt der Raum … / Auffällig ist, dass …* |

**推进手段**：用 *daneben, darüber, gegenüber, dahinter, links davon* 承接，而不是每句都重复 *Es gibt*。

**视角一致性**：一旦选定“从左到右”或“顺时针”，就不要来回跳。中文习惯“散点罗列”，德语读者期待**一条路线**。

## 八、B 2 范文：我的工作间

1. **Mein Arbeitszimmer – wie alles angeordnet ist**
我的工作间——一切是如何布置的

2. **Wenn man das Zimmer durch die einzige Tür betritt, steht man zunächst vor einem hohen Bücherregal, das die linke Wand fast vollständig einnimmt.**
从唯一的门走进房间，首先会站在一个高大的书架前，书架几乎占据了整面左墙。

3. **Die Bücher sind nach Themen sortiert und stehen dicht an dicht, dazwischen liegen einige Zeitschriftenstapel.**
书籍按主题分类，一本挨着一本紧密排列，中间夹着几摞杂志。

4. **Direkt daneben, in der hinteren linken Ecke, steht ein alter Ohrensessel, über dessen Lehne eine graue Wolldecke hängt.**
紧挨着旁边、在左后方的角落里，放着一把旧单人沙发椅，椅背上搭着一条灰色羊毛毯。

5. **Dem Eingang gegenüber, an der Stirnseite des Raumes, ist ein massiver Schreibtisch aus Eichenholz aufgestellt.**
正对入口、在房间的端面，摆放着一张厚重的橡木书桌。

6. **Darauf stehen ein Laptop, eine Schreibtischlampe und mehrere Tassen, die sich im Laufe der Woche angesammelt haben; daneben liegt ein aufgeschlagener Notizblock.**
桌上放着一台笔记本电脑、一盏台灯和几个杯子——它们是这一周里逐渐堆积起来的；旁边摊开着一本记事本。

7. **Über dem Tisch hängen drei gerahmte Fotos in einer waagerechten Reihe, während unter der Tischplatte ein flacher Papierkorb steht.**
书桌上方横向排成一列挂着三幅带框照片，而桌面下方则放着一个扁平的纸篓。

8. **An der rechten Wand befindet sich ein schmales Sideboard, auf dem eine Vase und zwei Kerzenhalter nebeneinander aufgereiht sind.**
右墙边有一个窄长的边柜，柜上并排摆放着一只花瓶和两个烛台。

9. **Zwischen Regal und Fenster ist ein Teppich ausgelegt, auf dem ein paar Schuhe verstreut liegen.**
书架和窗户之间铺着一块地毯，上面零散地放着几双鞋。

10. **Insgesamt wirkt der Raum eng, aber ordentlich – alles hat seinen festen Platz, und das ist vermutlich der Grund, warum ich hier so konzentriert arbeiten kann.**
总体来看，这个房间显得局促却整洁——每样东西都有固定的位置，而这大概正是我能在这里如此专注工作的原因。

### 范文结构拆解（可套用）

| 句 | 功能 | 语言手段 |
|---|---|---|
| 1 | 视角 + 第一件大物 | *Wenn man … betritt* + 地点前置倒装 |
| 2 | 内部细节（在 ① 之内） | *dicht an dicht, dazwischen* |
| 3 | 相邻物件 + 相对位置 | *Direkt daneben, in der … Ecke* |
| 4 | 对面墙 | *Dem Eingang gegenüber*（前置，Dativ） |
| 5 | 桌面细节（在 ④ 之上） | *Darauf …; daneben …* |
| 6 | 上下方位 + 从句嵌套 | *Über … hängen; während unter … steht* |
| 7 | 另一侧墙 + 排列 | *nebeneinander aufgereiht*（Zustandspassiv） |
| 8 | 地面 + 分散 | *ausgelegt, verstreut liegen* |
| 9 | 评价 | *Insgesamt wirkt … eng, aber ordentlich* |

### 变体一：橱窗（Schaufenster，商业风格）

> **Im Schaufenster der Bäckerei** sind vier runde Tische **kreisförmig angeordnet**. In der Mitte steht ein hoher Präsentierständer, **um den herum** mehrere Körbe mit Brot **aufgereiht** sind. **Links vom Eingang** ist eine Vitrine **aufgestellt**, in der die Torten **übereinander gestapelt** liegen. **An der Rückwand hängt** eine große Tafel, auf der die Tagesangebote **angebracht** sind.

### 变体二：图片描述（Bildbeschreibung，口语考试）

> **Auf dem Bild** sehe ich eine Küche. **Im Vordergrund links steht** ein gedeckter Tisch, **auf dem** Teller, Gläser und Besteck **liegen**. **Rechts daneben**, **am Fenster**, steht eine Frau, die gerade eine Kanne **auf die Arbeitsfläche stellt**. **Im Hintergrund hängen** zwei Regale **an der Wand**, in denen Geschirr **dicht an dicht** steht. **Auffällig ist**, dass die Küche sehr aufgeräumt wirkt.

## 九、错误清单（高频自查）

| ❌ 错误 | ✅ 正确 | 原因 |
|---|---|---|
| Das Bild hängt **an die** Wand. | Das Bild hängt **an der** Wand. | 静态用 Dativ |
| Ich lege das Buch **auf dem** Tisch. | Ich lege das Buch **auf den** Tisch. | 位移用 Akkusativ |
| Die Bücher **liegen** im Regal. | Die Bücher **stehen** im Regal. | 竖放用 stehen |
| Zwischen **den Stühle** steht ein Tisch. | Zwischen **den Stühlen** | Dativ 复数加 -n |
| Die Poster hängen über **der Sofa**. | über **dem** Sofa | Sofa 是中性 |
| Ich stelle das Glas **in dem** Schrank. | **in den** Schrank | 位移用 Akkusativ |
| **Auf dem Tisch ein Buch liegt.** | **Auf dem Tisch liegt ein Buch.** | 动词必须第二位 |
| Er hat das Bild an die Wand **gehangen**. | …an die Wand **gehängt**. | 动作义用弱变化 |
| Das Bild hat an der Wand **gehängt**. | … **gehangen**. | 状态义用强变化 |
| **Im** Regal steht eine Vase.（想说架子上） | **Auf dem** Regal steht eine Vase. | in = 内部 |
| Der Schlüssel liegt **im** Schloss. | steckt **im** Schloss | 插入用 stecken |
| **Gegenüber von** der Tür … | **Der Tür gegenüber** / **Gegenüber der Tür** | gegenüber 直接带 Dativ |

## 十一、总结：可迁移的摆放描述模型

描述任何空间的摆放，用这条**四维公式**：

> **视角（von wo aus）→ 定位（介词 + Dativ）→ 姿态（stehen/liegen/hängen…）→ 排列（in einer Reihe / verstreut…）→ 评价（wirkt…）**

背后的两条语言铁律：

1. **静态用 Dativ，动态用 Akkusativ；动词必须成对**（liegen↔legen, stehen↔stellen, hängen↔hängen）。
2. **德语必须说出姿态**：同样的“在那里”，书 *liegt*、瓶 *steht*、画 *hängt*、钥匙 *steckt*。中文的“在”没有这层信息，必须**主动补上**。

把上节课的**颜色 + 形状 + 尺寸**与本节的**位置 + 姿态 + 排列**叠加，你就拥有了 B 2 描述类任务的完整能力：任取一件物品，都能写出 *ein rechteckiger, 60 cm langer Holztisch, der an der linken Wand neben dem Regal steht* 这样信息密度足够的德语长句。
