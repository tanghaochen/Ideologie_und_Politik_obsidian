# 间接引语（新闻体）：第一、第二虚拟式与介词连接体系
**B 2 · 歌德考试相关（Lesen Teil 2 新闻文本 / Schreiben 转述 / Sprechen 转述与表态）**

---

## 0. 学习目标与知识地图

学完这一讲，你应当能做到四件事：

| 能力 | 具体表现 |
|---|---|
| ① 形式 | 写出第一虚拟式（KI）现在、过去、将来、被动的形式，并知道何时必须替换成第二虚拟式（KII）或 `würde` |
| ② 功能 | 区分 KI（中性转述）与 KII（非现实、礼貌、谨慎断言）各自不可互换的位置 |
| ③ 介词 | 用 `über / von / zu / bei / laut / nach / zufolge / gegenüber / an / auf / für / gegen / vor` 精确标注“谁说的、对谁说的、说的是什么、态度如何” |
| ④ 产出 | 把一段直接引语改写成新闻体间接引语，代词视角正确、介词格正确、语气标记正确 |

知识依赖关系（必须按顺序走）：

```
直接引语长什么样（已有基础）
        │
        ├──► 视角转换：代词、地点时间词          ← 简单，但不做会全错
        │
        ├──► 语气标记：KI 形式 → 替身规则 → KII   ← 本讲核心机制
        │
        └──► 内容框架：动词/名词 + 介词 + 格      ← 本讲重点
                     │
                     └──► 整合：一篇新闻的转述（实战）
```

一句话概括全讲：**虚拟式是“这是别人说的”的标签，介词是“谁、对谁、关于什么”的骨架。**两者缺一，转述就不可信。

## 1. 问题切入：为什么转述容易出错

看一段新闻发布会上市长的话（直接引语）：

> „Wir haben die Bauarbeiten an der Talbrücke im März begonnen. Die Kosten liegen bei 4,2 Millionen Euro. Ich bin darüber sehr verärgert."

初学者常写成：

> ✗ *Die Bürgermeisterin sagte, wir haben die Bauarbeiten im März begonnen. Die Kosten liegen bei 4,2 Millionen Euro. Ich bin darüber verärgert.*

三个错误，正好对应本讲三条主线：

1. **视角没转**：`wir` / `ich` 还站在原说话人的位置上。转述者必须站到自己这边：`sie`。
2. **语气没标**：读者无法判断这是记者的断言还是市长的说法——德语书面语要求用虚拟式标记“引用”。
3. **介词框架其实是对的**：`bei 4,2 Millionen Euro`（金额用 `bei`）不需要改，**介词宾语在转述中保持不变，只有代词要换**。这一点很多人误以为“转述要重写一切”，结果把介词也改坏了。

正确版本（形式细节第 5 节逐句拆解）：

> Die Bürgermeisterin sagte, sie **hätten** die Bauarbeiten an der Talbrücke im März begonnen. Die Kosten **lägen** derzeit **bei** 4,2 Millionen Euro. Sie **sei** darüber sehr verärgert.

注意：`hätten`、`lägen` 不是“假设”，而是**替身**（因为 `sie haben`、`sie liegen` 的 KI 形式与直陈完全相同，见 2.3）。

## 2. 核心一：第一虚拟式 KI —— 转述的中性语气

### 2.1 定义与本质

**KI = “我不为这句话的真实性负责，我只是把它转述出来”。**

通俗解释：直陈式是“我说这是真的”，KI 是“他说这是真的，真假你判断”。这正是新闻语体的核心需求——记者必须与消息来源保持距离。

**局限**：KI 只表示“转述”，**不表示怀疑**。想表达“我不信”，要用 `soll`（据说）或额外词汇（`angeblich`, `zweifelhaft`）。

### 2.2 形式：词干 + 虚拟式词尾

词尾固定为 **-e, -est, -e, -en, -et, -en**。⚠ 标记的是与直陈式**完全相同**、因此在这个人称上“不标记”的形式。

| 动词 | ich | du | er/sie/es | wir | ihr | sie/Sie |
|---|---|---|---|---|---|---|
| sein | sei | sei(e)st | **sei** | seien | seiet | seien |
| haben | habe | habest | **habe** | haben ⚠ | habet | haben ⚠ |
| werden | werde | werdest | **werde** | werden ⚠ | werdet | werden ⚠ |
| kommen | komme | kommest | **komme** | kommen ⚠ | kommet | kommen ⚠ |
| können | könne | könnest | **könne** | können ⚠ | könnet | können ⚠ |
| müssen | müsse | müssest | **müsse** | müssen ⚠ | müsset | müssen ⚠ |
| wissen | wisse | wissest | **wisse** | wissen ⚠ | wisset | wissen ⚠ |

**规律**：第三人称单数是 KI 的“主战场”，因为那里最容易与直陈区分（`komme` vs. `kommt`, `sei` vs. `ist`, `könne` vs. `kann`）。弱变化动词也一样有效：`er sage`, `er warne`, `er betone`。

### 2.3 各时间层只有一个“虚拟现在”和一个“虚拟过去”

德语没有“虚拟式过去时”。原句的现在时和过去时，在 KI 里合并处理：

| 原句（直陈） | 间接引语（KI） | 说明 |
|---|---|---|
| Er arbeitet viel. | Er **arbeite** viel. | 现在 |
| Er arbeitete viel. / Er hat viel gearbeitet. | Er **habe** viel **gearbeitet**. | 过去两种时态合并为“KI 现在完成” |
| Er wird viel arbeiten. | Er **werde** viel **arbeiten**. | 将来 |
| Er ist informiert worden. | Er **sei** informiert **worden**. | 被动的 KI |
| Er kann kommen. | Er **könne** kommen. | 情态动词 |
| Er muss es gewusst haben. | Er **müsse** es gewusst **haben**. | 情态 + 完成 |

### 2.4 关键机制：替身规则（Ersatzform）

这是 B 2 最容易失分的地方。逻辑只有一条：**虚拟式的作用是“标记”，如果一个形式标记不出来，就换一个能标记的。**

判断顺序（三步）：

```
想用 KI
  │
  ├─ ① KI 第三人称形式 ≠ 直陈？ ── 是 ──► 用 KI        er komme, sie sei, er könne
  │
  └─ 否（如 sie haben / sie liegen / sie müssen）
        │
        ├─ ② KII 形式 ≠ 直陈过去时？ ── 是 ──► 用 KII   sie hätten, sie lägen, sie müssten
        │
        └─ 否（弱变化动词：machten, sagten 与过去时同形）
              │
              └─ ③ 用 würde + 不定式                      sie würden Überstunden machen
```

例：

| 原句 | ✗ 无效 KI | ✓ 正确转述 | 触发哪一步 |
|---|---|---|---|
| „Wir haben keine Zeit." | *sie haben keine Zeit | sie **hätten** keine Zeit | ② |
| „Wir kommen später." | *sie kommen später | sie **kämen** später | ② |
| „Wir müssen warten." | *sie müssen warten | sie **müssten** warten | ② |
| „Wir machen Überstunden." | *sie machen Überstunden | sie **würden** Überstunden **machen** | ③（KII = machten = 过去时，无法区分） |
| „Ich bin zufrieden." | — | sie **sei** zufrieden | ① |

**一个必须记住的限制**：`würde` 不能和 `sein / haben / 情态动词` 连用。
✗ *sie würden keine Zeit haben* → ✓ `sie hätten keine Zeit`
✗ *er würde zufrieden sein* → ✓ `er wäre zufrieden`
✗ *er würde kommen können* → ✓ `er könnte kommen`

## 3. 核心二：第二虚拟式 KII —— 四个不可替代的位置

### 3.1 形式速览

| | 形式 | 例 |
|---|---|---|
| 现在 | 强变化词干 + 变音 + 过去时词尾 | wäre, hätte, käme, gäbe, wüsste, könnte, müsste |
| 过去 | hätte / wäre + 过去分词 | hätte gesagt, wäre gekommen |
| 被动 | würde + 过去分词 + werden | würde informiert werden |
| 弱动词 | 与过去时同形 → 用 würde | würde machen（不用 machte） |

### 3.2 四个功能域（与 KI 分工明确）

**① 非现实条件（新闻评论、分析常用）**
> Wenn die Stadt die Brücke früher saniert **hätte**, **wäre** der Schaden geringer **gewesen**.
> Die Kosten **wären** bei rechtzeitiger Warnung vermeidbar **gewesen**.

**② 非现实愿望 / 未实现的可能**
> Man **hätte** die Sperrung längst ankündigen **können**.

**③ 礼貌与委婉（采访、提问）**
> **Könnten** Sie uns dazu eine Stellungnahme geben?
> Ich **hätte** eine Frage zu dem Bericht **über** die Bauarbeiten.

**④ 记者式谨慎断言（B 2→C 1 的关键语感）**
> Ein Erfolg **wäre** überraschend. —— 比 *Ein Erfolg ist überraschend* 明显更谨慎
> Das **dürfte** teuer **werden**. —— `dürfte` = 很可能，但不打包票
> Das **wäre** ein Novum in der Geschichte des Landes.

**⑤ 非现实比较**：`als ob / als wenn + KII`，或 `als + KII`
> Der Minister tat, **als ob** er nichts davon **wüsste**. / **als wüsste** er nichts davon.

### 3.3 KI 与 KII 的分工表

| 场景 | 用哪个 | 例句 |
|---|---|---|
| 中性转述，形式可区分 | **KI** | Sie sagte, sie **sei** nicht informiert worden. |
| 中性转述，KI 与直陈同形 | **KII（替身）** | Sie sagte, sie **hätten** keine Zeit. |
| 非现实、假设 | **KII** | Wenn er das **gewusst hätte**, **hätte** er reagiert. |
| 礼貌请求 | **KII** | **Würden** Sie das bestätigen? |
| 谨慎判断 | **KII** | Das **könnte** problematisch werden. |
| 未经证实的传闻 | **soll** | Der Minister **soll** von den Plänen gewusst **haben**. |
| 当事人自称 | **will** | Er **will** nichts davon gewusst **haben**. |

> 提醒：`soll` / `will` 是新闻中极高频的“距离化”手段，与虚拟式互补：`soll` 表示“据说”，`will` 表示“他自称”。这两个词不需要虚拟式，但语义上承担了同样的“我不担保”功能。

## 4. 核心三：介词连接体系（本讲重点）

转述一句话，实际要处理四类信息，每类有各自的介词工具箱。

```
① 来源层：谁说的 / 向谁说的  → laut, nach, zufolge, gegenüber, bei, aus, durch, in, auf
② 内容层：说的是什么        → über (+A), von (+D), zu (+D)
③ 对象层：涉及谁/什么       → mit (+D), gegen (+A), für (+A), an (+D/A), auf (+A)
④ 场合层：在什么场合        → bei (+D), auf (+D), in (+D), anlässlich (+G)
```

### 4.1 内容层：`über` 与 `von` 的真正区别

这是 R 1 要求里最容易混的一对。核心区别在于**论述的完整度**：

| | `über + Akk` | `von + Dat` |
|---|---|---|
| 语义 | 完整主题、系统性论述、报道对象 | 提及、片段、亲历转述、具体所指 |
| 搭配 | einen Vortrag / einen Bericht / eine Rede **über** | erzählen / berichten / sprechen **von** |
| 例 | Sie sprach **über** den Klimawandel.（一场完整报告） | Sie sprach **von** ihren Plänen.（顺带提到） |
| 提问 | **Worüber** sprichst du?（主题是什么） | **Wovon** sprichst du?（你指哪件事/哪个人） |
| 陷阱 | — | `ein Bericht **von** Müller` = 作者是 Müller；`ein Bericht **über** Müller` = 内容是 Müller |

两可但有细微差别的一对：
> Der Reporter berichtete **über** den Unfall. （事件作为报道主题，完整）
> Der Reporter berichtete **von** dem Unfall. （他现场所见所闻的叙述）

### 4.2 来源层：新闻的“署名系统”

| 介词 | 格 | 位置 | 例 |
|---|---|---|---|
| `laut` | Dat | 前置，通常不带冠词 | **Laut** Bericht **sei** die Lage ruhig. / **Laut** einem Sprecher … |
| `nach` | Dat | 前置 | **Nach** Angaben der Polizei … / **Nach** Aussage des Ministers … |
| `zufolge` | Dat | **后置**（必须） | Dem Bericht **zufolge** … / Angaben der Polizei **zufolge** … |
| `gegenüber` | Dat | 前置或后置 | Er äußerte sich **gegenüber** den Journalisten … |
| `bei` | Dat | 机构/人（被咨询方） | Ich habe mich **bei** der Behörde erkundigt. |
| `aus` | Dat | 圈子、文件 | **Aus** Regierungskreisen hieß es … / wie **aus** dem Gutachten hervorgeht |
| `durch` | Akk | 中介人（避免双重 von） | **Durch** eine Kollegin habe ich **von** dem Vorfall erfahren. |
| `in` | Dat | 声明载体 | **In** einer Erklärung **hieß** es … |
| `auf` | Akk | 应询 | **Auf** Anfrage teilte die Behörde mit, … |

**三条硬规则**：
1. `laut` 不与定冠词连用：✗ *laut des Berichts* → ✓ `laut dem Bericht` / `laut Bericht` / `dem Bericht zufolge`
2. `zufolge` 永远跟在名词后：✗ *zufolge dem Bericht* → ✓ `dem Bericht zufolge`
3. 不要连用两个 `von`：✗ *von einer Kollegin von dem Vorfall* → ✓ `durch eine Kollegin von dem Vorfall` / `von einer Kollegin über den Vorfall`

### 4.3 对象层：动词固定搭配（附格）

这些搭配在转述中会原样保留，**只换代词，不换介词**——所以必须记死。

| 介词 + 格 | 常用动词 / 名词 | 例句（间接引语） |
|---|---|---|
| **über + A** | berichten, sprechen, diskutieren, sich beschweren, klagen, sich informieren, verhandeln, sich ärgern, nachdenken | Er sagte, die Regierung **verhandle über** die Mehrkosten. |
| **von + D** | berichten, erzählen, sprechen, halten (评价), ausgehen, überzeugt sein, abhängen | Sie betonte, sie **halte viel von** dem Vorschlag. |
| **zu + D** | sich äußern, Stellung nehmen, auffordern, führen zu, beitragen zu | Die Behörde **äußerte sich nicht zu** den Vorwürfen. |
| **an + D** | zweifeln, Kritik äußern, teilnehmen, sich beteiligen, arbeiten an, es mangelt an | Niemand **zweifle an** der Glaubwürdigkeit des Zeugen. |
| **an + A** | glauben, sich erinnern, appellieren, sich wenden, denken (想到) | Er **appellierte an** die Bürger, ruhig zu bleiben. |
| **auf + A** | hinweisen, verweisen, sich beziehen, hoffen, warten, reagieren, sich einigen | Der Sprecher **wies auf** Widersprüche **hin**. |
| **auf + D** | bestehen, beharren, beruhen, basieren | Die Regierung **beharrte auf** ihrer Position. |
| **bei + D** | sich informieren, sich beschweren, sich erkundigen, nachfragen | Die Bürger könnten sich **bei** uns **über** den Stand informieren. |
| **mit + D** | sprechen, verhandeln（对手方）, sich befassen, rechnen mit, drohen mit | Sie **würden mit** dem Land **über** die Kosten **verhandeln**. |
| **gegen + A** | ermitteln, protestieren, sich wehren, verstoßen, Vorwürfe erheben | Die Polizei **ermittle gegen** den Fahrer. |
| **für + A** | sich interessieren, sich einsetzen, werben, danken, halten für | Er **würde sich für** eine Lösung **einsetzen**. |
| **vor + D** | warnen, sich fürchten, schützen | Er **warnte vor** voreiligen Schlüssen. |
| **nach + D** | fragen, suchen, sich erkundigen | Sie **hätten sich nach** den Fristen **erkundigt**. |

**黄金句式（把“人—事—态度”三层一次排好）**：
> **bei** + 来源人/机构 + **über** + 内容 + 动词
> Sie **beschwerte sich bei** ihrem Vorgesetzten **über** die ständigen Überstunden.
> Die Bürger können sich **bei** uns **über** den Stand der Arbeiten informieren.

### 4.4 名词化短语：新闻体的压缩手段

| 短语 | 含义 | 例 |
|---|---|---|
| in seinem Bericht **über** + A | 在他的报告中（内容） | **In** ihrem Bericht **über** die Bauarbeiten … |
| nach Angaben **von** / + Gen | 据……称 | **Nach** Angaben des Ministeriums … |
| auf Nachfrage / auf Anfrage | 应询时 | **Auf** Nachfrage räumte er ein, … |
| bei der Vorstellung + Gen | 在……介绍时 | **Bei** der Vorstellung des Gutachtens … |
| angesichts + Gen | 鉴于 | **Angesichts** der Kosten … |
| in Bezug **auf** + A | 关于 | **In Bezug auf** die Fristen … |
| hinsichtlich / bezüglich + Gen | 就……而言 | **Hinsichtlich** der Finanzierung … |
| demnach / demzufolge | 据此（副词，无需介词） | Die Kosten **lägen demnach** bei 4,2 Millionen Euro. |

## 5. 机制整合：逐句示范

**原文（直接引语）**

> „Wir haben die Bauarbeiten an der Talbrücke im März begonnen. Wegen der Verzögerungen liegen die Kosten inzwischen bei 4,2 Millionen Euro. Ich bin darüber sehr verärgert. Wir werden im Herbst mit dem Land über die Mehrkosten verhandeln. Die Bürger können sich bei uns über den Stand der Arbeiten informieren."

**转述文本**

> Die Bürgermeisterin sagte, sie **hätten** die Bauarbeiten an der Talbrücke im März **begonnen**. Wegen der Verzögerungen **lägen** die Kosten inzwischen **bei** 4,2 Millionen Euro. Sie **sei** **darüber** sehr verärgert. Sie **würden** im Herbst **mit** dem Land **über** die Mehrkosten **verhandeln**. Die Bürger **könnten** sich **bei ihnen über** den Stand der Arbeiten **informieren**.

**逐句决策表**

| 原句构件 | 做了什么 | 依据 |
|---|---|---|
| `Wir haben … begonnen` → `sie hätten … begonnen` | 代词 wir→sie；KI 形式 `sie haben` = 直陈 → 用 KII | 替身规则② |
| `liegen die Kosten` → `lägen` | 复数 KI `liegen` = 直陈 → KII | 替身规则② |
| `bei 4,2 Millionen Euro` | **原样保留**：金额用 `bei + Dat` | 介词宾语不因转述而变 |
| `Ich bin … verärgert` → `Sie sei` | `sei` 与 `ist` 可区分 → KI；`ich` → `sie` | 规则① |
| `darüber` | 代副词回指前句内容，**不改** | 回指对象在语境中不变 |
| `Wir werden … verhandeln` → `sie würden … verhandeln` | 将来 KI `werden` = 直陈 → `würden` | 规则②/③ |
| `mit dem Land über die Mehrkosten` | 双介词结构：`mit`（对手方）+ `über`（议题） | 内容层/对象层分工 |
| `können` → `könnten` | 复数 KI `können` = 直陈 → KII | 规则② |
| `bei uns` → `bei ihnen` | **介词短语内部的代词也要换** | 视角转换 |

**反向操作：转述 → 新闻压缩体**

> **Nach** Angaben der Bürgermeisterin **haben** die Bauarbeiten an der Talbrücke im März **begonnen**. Die Kosten **liegen demnach bei** 4,2 Millionen Euro. **Mit** dem Land **wolle** die Stadt im Herbst **über** die Mehrkosten **verhandeln**.

两点说明：
- 有了 `nach Angaben` / `demnach` 这样的**来源标记**，新闻中常用直陈式——因为“谁说的”已经由介词标出，无需虚拟式再加标签。这是**语体差异，不是错误**。
- `wolle` 是 `wollen` 的 KI，用于转述“当事方表示愿意做某事”，比 `würde` 更贴新闻语体。

6. Wir haben uns ___ der Verbraucherzentrale ___ die neuen Gebühren informiert.
7. ___ Angaben der Polizei ereignete sich der Unfall gegen sechs Uhr.
8. ___ einem Sprecher des Ministeriums sei die Entscheidung noch nicht gefallen.
9. Sie beschwerte sich ___ ihrem Vorgesetzten ___ die ständigen Überstunden.
10. Die Regierung wies die Vorwürfe zurück und beharrte ___ ihrer Position.

### 任务 C｜新闻压缩（约 6 分钟）
把下面三句间接引语压缩成**两句新闻体**，至少使用三种不同的来源/内容介词（`laut / nach / zufolge / zu / über / gegenüber` 等）：

> Ein Sprecher des Ministeriums sagte, die Verhandlungen hätten in konstruktiver Atmosphäre stattgefunden. Man werde sich im Januar erneut treffen. Zu den Einzelheiten könne er sich nicht äußern.

### 任务 D｜改错（6 句，约 4 分钟）

1. Er sagte, er hat keine Zeit für ein Interview.
2. Sie berichtete über ihren Erlebnissen.
3. Laut des Berichts sei die Lage ruhig.
4. Wenn ich Minister sein würde, würde ich die Regel ändern.
5. Die Sprecherin erklärte, dass sie sei nicht informiert worden.
6. Der Minister äußerte sich über die Vorwürfe nicht.

### 评分标准（自评/互评）

| 维度 | 分值 | 达标表现 |
|---|---|---|
| 虚拟式形式 | 30% | KI 形式正确；KI = 直陈处正确使用 KII 或 würde；未出现 *würde sein / würde haben* |
| 介词与格 | 30% | 介词选择正确、格正确；未误改介词宾语；`laut/zufolge` 位置正确 |
| 视角与语序 | 20% | 代词、物主词、`bei uns → bei ihnen` 全部转换；`dass` 从句中虚拟式位于句末 |
| 语体 | 20% | 转述句用虚拟式；新闻压缩句用来源标记 + 直陈/虚拟式一致；无口语化冗余 |

**异常处理**：若某句 KI 与直陈同形而你又拿不准 KII，就改用 `würde + 不定式`（弱变化动词）或换用带来源标记的直陈结构（`Dem Bericht zufolge …`）——这不是最优，但不会错到扣分。

## 7. 边界与总结

**这套规则什么时候不适用或可放宽**

1. **口语与半正式文体**：语境明确时常用直陈（`Er sagte, er kommt später`）。歌德 B 2 笔试的转述题仍以虚拟式为标准答案。
2. **来源已由介词标明**：`laut / nach Angaben / zufolge` 后接直陈在新闻中完全可接受；反之，`sagte / erklärte / betonte` 后的从句必须虚拟式。
3. **KI 与直陈同形且语境清晰**：复数形式（`sie kommen`）在实际文本中不总被替换，但考试评分倾向要求 KII，稳妥做法是替换。
4. ** `über` 与 `von` 并非绝对对立**：`berichten über / von` 常可互换，只是论述完整度不同；但 `halten von`（评价）、`sprechen von`（指称）不能用 `über` 替换。
5. ** `laut` 的格**：标准语为第三格；口语中偶见第二格，不宜模仿。
6. **虚拟式不表示真假**：要表达怀疑必须另加手段（`soll`, `angeblich`, `zweifelhaft`）。

**可迁移模型：转述的三环结构**

```
来源环  → laut / nach / zufolge / gegenüber / bei / aus / durch / in / auf
          （谁说的、向谁说的、依据什么文件）
内容环  → über (+A) / von (+D) / zu (+D) + 虚拟式标记
          （说了什么，完整性如何）
态度环  → an / auf / von / gegen / für / vor (+相应格) + KII
          （评价、怀疑、要求、警告）
```

任何一句转述，只要按这三环检查一遍，就不会出现“代词错、语气无标记、介词错格”这三类高频错误。反过来，读新闻时也可以按这三环拆解：先找来源介词，再找内容介词，最后看动词的介词搭配与语气——这是 B 2 阅读长难句的通用手术刀。

## 8. 练习答案

**任务 A**

1. Er sagte, er **habe** **von** dem Vorfall **aus** der Presse **erfahren**.
2. Sie sagten, sie **müssten** **bei** der nächsten Sitzung **über** den Antrag **entscheiden**.（`sie müssen` = 直陈 → KII）
3. Er sagte, er **könne** Ihnen **zu** dem Ergebnis nichts **sagen**.
4. Der Sprecher sagte, die Polizei **habe** **gegen** mehrere Personen **ermittelt**.
5. Sie sagten, sie **hätten** sich **bei** der Behörde **nach** den Fristen **erkundigt**.（`sie haben` = 直陈 → KII）
6. Er sagte, er **warne** ausdrücklich **vor** voreiligen Schlüssen.
7. Sie sagte, die Zahlen **seien** ihr seit Montag bekannt.（`uns` → `ihr`）
8. Er sagte, er **sei** **davon** **ausgegangen**, dass der Termin **stehe**.

**任务 B**

1. **über** die Ergebnisse（+Akk）
2. **von** ihren Beobachtungen（+Dat）
3. **an** der Glaubwürdigkeit（+Dat）
4. **auf** die Risiken（+Akk）
5. **zu** dem Vorwurf（+Dat）
6. **bei** der Verbraucherzentrale（+Dat）／ **über** die neuen Gebühren（+Akk）
7. **Nach** Angaben（+Dat）
8. **Laut** einem Sprecher（+Dat）／ 也可 `Einem Sprecher des Ministeriums zufolge`
9. **bei** ihrem Vorgesetzten（+Dat）／ **über** die ständigen Überstunden（+Akk）
10. **auf** ihrer Position（+Dat，`beharren auf` 用第三格）

**任务 C（参考答案）**

> **Einem Sprecher des Ministeriums zufolge** verliefen die Verhandlungen in konstruktiver Atmosphäre. Ein weiteres Treffen **sei** für Januar geplant; **Angaben zu** den Einzelheiten lehnte der Sprecher ab.

（用了 `zufolge`、`zu`、以及名词化 `Angaben zu`；`sei` 保留 KI 作为“计划未定”的距离化标记。）

**任务 D**

1. → Er sagte, er **habe / hätte** keine Zeit für ein Interview.（`hat` 必须在从句中变虚拟式）
2. → Sie berichtete **von** ihren Erlebnissen.（或 `über ihre Erlebnisse` ——介词决定格）
3. → **Laut dem Bericht** / **Dem Bericht zufolge** sei die Lage ruhig.（`laut` 不与第二格定冠词连用）
4. → Wenn ich Minister **wäre**, würde ich die Regel ändern.（`sein` 的 KII 是 `wäre`，不用 `würde sein`）
5. → Die Sprecherin erklärte, dass sie nicht informiert worden **sei**.（`dass` 从句中虚拟式位于句末）
6. → Der Minister äußerte sich **zu den Vorwürfen** nicht.（`sich äußern` 固定搭配 `zu + Dat`）
