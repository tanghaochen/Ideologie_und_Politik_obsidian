# 德语 B 2｜购物与客服沟通：线下购物与网店的售前、下单、售后、退换货

> 前三课解决“描述”（物品、摆放、动作），本课解决“**交涉**”。这是歌德 B 2 写作（正式邮件、投诉信、询问信）与口语（电话、协商、表达不满）中得分最高、也最容易暴露语域错误的主题。

---

## 一、学习目标与知识地图

学完本主题，你应当能：

1. **判断诉求**：分清 *Widerruf*（撤销）、*Gewährleistung*（瑕疵担保）、*Garantie*（厂商保修）、*Kulanz*（通融）四种情况，并选用对应的语言。
2. **写出 7 段式正式邮件**：主题行 → 称呼 → 事由 → 问题描述 → 证据 → 诉求 + 期限 → 结束语。
3. **掌握礼貌三级**：直接命令 → Konjunktiv II → 名词化正式结构，并知道哪种场合用哪一级。
4. **电话与聊天**：用固定套语完成“说明问题—被转接—要求书面确认”的完整流程。
5. **准确使用功能动词结构和介词搭配**：*eine Beschwerde einlegen, sich erkundigen nach, Anspruch haben auf*。

```
知识依赖链：
诉求类型判断（法律/常识层）─┐
场景词汇 ──────────────────┼→ 礼貌语域(3级) → 邮件7段结构 → 电话/聊天 → 综合实战
介词搭配与功能动词 ────────┘
```

**核心命题**：本主题的难点在于两点：

- **机制 A：你说的那句话，决定了你主张哪种权利**。同一件商品，写“我不想要了”是 *Widerruf*（14 天内无条件）；写“商品有瑕疵”是 *Gewährleistung*（法定 2 年）。用错词，卖家就按另一套规则处理你。
- **机制 B：语域**。*Ich will mein Geld zurück* 在聊天里可以，在邮件里几乎等于宣战。B 2 评分标准明确考察“angemessene Anrede und Schlussformel”与“Register”。

## 二、第一层：先判断你处在哪种情况

> ⚠️ 以下为德国/欧盟一般性规则，用于**语言学习中的情境定位**，不是法律咨询。具体条件因商店、商品类型、合同条款而异，下单前应阅读对方的 *Widerrufsbelehrung* 与 *AGB*。

### 四种诉求的决策树

```
发生了什么？
│
├─ 商品没坏，但我不想要了 / 不合适 / 颜色不对
│   ├─ 网购、电话、邮购（Fernabsatz）→ Widerrufsrecht
│   │    14 天内、无需理由；须寄回；例外：定制商品、已拆封的
│   │    卫生用品、已开始的数字内容、易腐品
│   └─ 实体店买的 → 无法律规定，Umtausch 属于 Kulanz（商家自愿）
│        语言上要用“请求”而非“要求”：Könnten Sie ... ?
│
├─ 商品有瑕疵（defekt / beschädigt / falsch / unvollständig）
│   → Gewährleistung / Sachmängelhaftung
│     2 年内（新货）由卖家负责；先给卖家“补救机会”：Nacherfüllung
│     = Reparatur 或 Ersatzlieferung（由买家选）
│     失败或拒绝后 → Rücktritt（退货退款）、Minderung（减价）、
│     Schadensersatz
│     语言：Ich mache einen Mangel geltend. / Ich beanstande ...
│
├─ 超过 2 年，或有厂商保修卡
│   → Garantie（Herstellergarantie，自愿性质，条件看 Garantiekarte）
│     语言：Ich möchte die Garantie in Anspruch nehmen.
│
├─ 运输损坏 / 少发 / 发错
│   → Lieferproblem：立刻报备、拍照、要求补发或退款
│     语言：Die Sendung ist beschädigt angekommen.
│
└─ 法律上没依据，但希望商家通融
    → Kulanz：语气必须软化，给对方留面子
      语言：Ich würde mich freuen, wenn Sie mir entgegenkommen könnten.
```

### 语言选择的对照表（关键）

| 情况 | 不能说的话 | 该说的话 | 效果 |
|---|---|---|---|
| 不想要了（网购） | Der Artikel ist defekt.（撒谎） | Ich möchte von meinem Widerrufsrecht Gebrauch machen. | 无需理由、卖家必须接受 |
| 商品有瑕疵 | Ich möchte den Artikel zurückgeben. | Der Artikel weist einen Mangel auf: ... | 卖家承担运费、可选择换新 |
| 实体店换货 | Ich habe ein Recht auf Umtausch. | Ich würde gern umtauschen – wäre das möglich? | 不激化，靠通融 |
| 求通融 | Sie müssen ... | Ich wäre Ihnen dankbar, wenn ... | 保留关系 |

> **一句话总结**：*Widerruf* 用于“我不想要”，*Mangel* 用于“它有问题”，*Kulanz* 用于“请帮个忙”。三者的语言温度依次升高。

## 四、第三层：六个核心机制

### 机制 A｜礼貌三级阶梯（语域必须匹配场合）

| 级别 | 结构 | 例句 | 适用 |
|---|---|---|---|
| **1 直接** | 命令式 / *Ich will* | Schicken Sie mir das Geld zurück. | 只用于熟人、紧急、或故意强硬 |
| **2 委婉** | Konjunktiv II：*könnte, würde, hätte, wäre* / *Ich möchte …* | **Könnten Sie** mir den Betrag bitte erstatten? | 邮件、电话的**标准级** |
| **3 正式** | 名词化 + 被动 + 功能动词 | **Ich möchte Sie bitten**, mir den Betrag **zu erstatten**. / **Ich wäre Ihnen dankbar, wenn** Sie … | 投诉升级、律师信 |

**Konjunktiv II 常用套语**（背下来直接可用）：

- Könnten Sie mir bitte mitteilen, ob …?
- Ich würde gern wissen, wann …
- Wäre es möglich, dass …?
- Ich hätte eine Frage zu …
- Es wäre nett / hilfreich, wenn Sie …
- Dürfte ich Sie um etwas bitten?
- Ich wäre Ihnen sehr dankbar, wenn Sie mir … zusenden könnten.

> ⚠️ 注意 konjunktiv II 里 *hätte/wäre/könnte* 是原形；其余动词用 **würde + 不定式**（*würde erstatten*），不要写 ❌ *erstattete*（那是第二虚拟式的旧式形式，现代德语少用）。

### 机制 B｜间接疑问：动词跑到最后

直接问句 → 间接问句，语序由“动词第二位”变成“动词在句末”：

| 直接 | 间接（礼貌） |
|---|---|
| Wann kommt das Paket? | Könnten Sie mir sagen, **wann das Paket kommt**? |
| Ist der Artikel lieferbar? | Ich möchte wissen, **ob der Artikel lieferbar ist**. |
| Wie hoch sind die Versandkosten? | Ich hätte gern gewusst, **wie hoch die Versandkosten sind**. |
| Haben Sie die Ware schon verschickt? | Darf ich fragen, **ob Sie die Ware schon verschickt haben**? |

**疑问词表**：*ob*（是否）、*wann, wie lange, wie hoch, warum, welche, wo, wer*。**ob** 用于“是/否”问句，必须加。

### 机制 C｜被动与“可否”的表达（说明书、客服对答）

| 结构 | 例句 | 语域 |
|---|---|---|
| **Vorgangspassiv（现在时）** | Die Ware **wird** innerhalb von zwei Werktagen **geliefert**. | 中性/正式 |
| **Passiv + Modalverb** | Der Artikel **kann** kostenlos **zurückgeschickt werden**. | 最常见 |
| **sein + zu + Infinitiv** | Die Rücksendekosten **sind** vom Kunden **zu tragen**. | 很正式（AGB） |
| **sich lassen + Infinitiv** | Der Fehler **lässt sich** leider nicht **nachvollziehen**. | 客服常用，显专业 |
| **-bar 形容词** | lieferbar, umtauschbar, erstattungsfähig, reparierbar, waschbar | 简洁 |
| **sich + 中间态** | Das Gerät **schaltet sich** nach wenigen Sekunden **ab**. | 描述故障 |

> **完成时被动**：*ist geliefert **worden***（不是 *geworden*）。这是 B 2 高频错点：
> ❌ Das Paket ist nicht geliefert geworden. → ✅ Das Paket **ist** nicht geliefert **worden**.

### 机制 D｜介词搭配 + 功能动词结构（提分最明显）

**动词/形容词 + 固定介词**：

| 搭配 | 例句 |
|---|---|
| sich beschweren **über + A** | Ich beschwere mich **über den defekten Artikel**. |
| sich erkundigen **nach + D** | Ich erkundige mich **nach der Lieferzeit**. |
| sich wenden **an + A** | Bitte wenden Sie sich **an unseren Kundenservice**. |
| bitten **um + A** | Ich bitte **um eine schnelle Bearbeitung**. |
| sich bedanken **für + A** | Vielen Dank **für Ihre Rückmeldung**. |
| reagieren **auf + A** | Sie haben **auf meine E-Mail** nicht reagiert. |
| antworten **auf + A** | Bitte antworten Sie **auf diese Nachricht**. |
| zuständig sein **für + A** | **Für Retouren** ist eine andere Abteilung zuständig. |
| zufrieden sein **mit + D** | Ich bin **mit dem Service** nicht zufrieden. |
| enttäuscht sein **von + D** | Ich bin **von der Qualität** enttäuscht. |
| abweichen **von + D** | Die Lieferung weicht **von der Beschreibung** ab. |
| Anspruch haben **auf + A** | Ich habe **Anspruch auf** eine Ersatzlieferung. |
| Garantie haben **auf + A** | Auf das Gerät haben Sie zwei Jahre Garantie. |
| sich einigen **auf + A / mit + D** | Wir haben **uns auf** einen Preisnachlass **geeinigt**. |
| hinweisen **auf + A** | Ich möchte **auf** einen Fehler **hinweisen**. |
| verzichten **auf + A** | Ich verzichte **auf** eine Reparatur. |
| sich beziehen **auf + A** | Ich beziehe mich **auf** Ihr Schreiben vom 12. Mai. |

**功能动词结构（Funktionsverbgefüge）**——把“动词”换成“名词+固定动词”，语域立刻升高：

| 口语/简单 | 正式/书面 |
|---|---|
| sich beschweren | **eine Beschwerde einlegen / vorbringen** |
| fragen | **eine Anfrage stellen** |
| fordern | **eine Forderung erheben** |
| einen Fehler melden | **einen Mangel geltend machen / beanstanden** |
| kündigen | **den Vertrag kündigen / vom Vertrag zurücktreten** |
| entscheiden | **eine Entscheidung treffen** |
| eine Lösung finden | **eine Lösung finden / erzielen** |
| sich beziehen auf | **Bezug nehmen auf + A** |
| etwas klarstellen | **Stellung nehmen zu + D** |
| Rücksicht nehmen auf + A | （考虑到） |
| zur Verfügung stellen | （提供） |
| in Anspruch nehmen | （使用/主张：die Garantie in Anspruch nehmen） |

### 机制 E｜正式邮件的 7 段结构

| # | 段落 | 内容 | 常用语 |
|---|---|---|---|
| 1 | **Betreff** | 主题行必须含**订单号 + 问题** | *Reklamation zu meiner Bestellung Nr. 4512 – defekter Wasserkocher* |
| 2 | **Anrede** | 称呼 | *Sehr geehrte Damen und Herren,*（不知道姓名时必须有） |
| 3 | **Bezug（事由）** | 何时买了什么、订单号 | *am 12. April habe ich in Ihrem Online-Shop … bestellt* |
| 4 | **Problem** | 客观描述，不带情绪 | *Leider musste ich feststellen, dass …* |
| 5 | **Belege** | 证据、附件 | *Zwei Fotos habe ich dieser E-Mail beigefügt.* |
| 6 | **Forderung + Frist** | 具体要求 + 期限 | *Ich bitte Sie daher, mir bis zum 30. April … zu erstatten.* |
| 7 | **Grußformel** | 结束语 | *Mit freundlichen Grüßen* + 姓名 |

**结构规则（写作评分点）**：

- 开头**不用** *Hallo*，结尾**不用** *Tschüss*（正式邮件）。
- 首句**不能**只写 *Ich schreibe Ihnen, weil …*——太弱。用 *Bezug* 段直接给事实。
- **Frist 必须具体日期**：❌ *so schnell wie möglich* → ✅ *bis zum 30. April*。
- **升级句**要礼貌但明确：*Sollte ich bis zum genannten Datum keine Rückmeldung erhalten, behalte ich mir weitere Schritte vor.*（保留后续措施的权利）

### 机制 F｜时间与条件表达

| 结构 | 例句 | 注意 |
|---|---|---|
| **innerhalb von + D** | innerhalb **von** 14 **Tagen** | 必须带 von + Dativ |
| **binnen + D** | **binnen** einer Woche | 同义，更书面 |
| **bis (zu) + D** | **bis zum** 30. April / **bis spätestens** Freitag | 期限终点 |
| **ab + D** | **ab dem** Datum der Lieferung | 起点 |
| **vor Ablauf + G** | **vor Ablauf der** Frist | 期限届满前 |
| **um … zu** | Ich schreibe Ihnen, **um** den Vorgang **zu klären**. | 目的 |
| **Sollte / Falls**（条件前置，无 wenn） | **Sollte** die Ware nicht innerhalb einer Woche eintreffen, … | 正式语域，动词前置 |
| **sofern** | **Sofern** ein Mangel vorliegt, … | 很正式 |

> *falls / sollte* 的区别：*falls* 中性；***sollte*** 更客气、更正式，是邮件里表达“万一”的优选。

| ❌ 错误 | ✅ 正确 | 原因 |

## 九、总结：可迁移模型

任何一次购物交涉，走这条**五步流程**：

> **① 定性质**（我不想要 / 它有瑕疵 / 求通融）→ **② 选语域**（聊天：口语；邮件：Konjunktiv II + 名词化）→ **③ 给事实**（日期、订单号、金额、具体缺陷、附件）→ **④ 提诉求 + 定期限**（两个选项 + 具体日期）→ **⑤ 留升级空间或致谢**

底层只有三条铁律：

1. **词就是诉求**：*Widerruf*（不想要，14 天）/ *Mangel & Gewährleistung*（有瑕疵，2 年）/ *Garantie*（厂商保修）/ *Kulanz*（求通融）。用错词，你就在主张另一套权利。
2. **语域决定成败**：正式邮件 = *Sehr geehrte … / Konjunktiv II / 被动与名词化 / Mit freundlichen Grüßen*；聊天才用 *Hallo, ich hab …*。混用是 B 2 最刺眼的失分点。
3. **诉求必须可执行**：具体日期（*bis zum 30. April*）、具体金额、具体动作（*erstatten / zusenden / zurückschicken*），而不是“请尽快处理”。

四课合起来，你的 B 2 描述与交涉能力已经闭环：

> *Auf dem Fensterbrett steht eine rechteckige, 40 cm lange Holzkiste. Beim Aufräumen habe ich sie heruntergenommen und festgestellt, dass der Deckel gebrochen ist. Deshalb habe ich dem Verkäufer eine E-Mail geschrieben und ihn gebeten, mir bis zum 30. Mai ein Ersatzteil zuzusenden.*

**物品（形状 + 尺寸）→ 位置（介词 + 姿态）→ 动作（可分动词 + 时间连接）→ 交涉（语域 + 诉求 + 期限）**：一条完整的能力链。
