## ① 能力构念：B 2 输出能力的 L 0–L 5 拆解

一切出题的起点是"考什么"。歌德 B 2 的公开评分维度是 **Erfüllung（任务完成）、Kohärenz（连贯）、Wortschatz（词汇）、Strukturen（结构）**，口语另加 Aussprache。训练靶必须照抄这四维，而不是模糊的"多学德语"。把"输出能力"拆成七层部件后，每类题型才有明确的打击目标：

```mermaid
flowchart TB
  subgraph LAYERS["B2 输出能力的七个部件"]
    L0["L0 语用/体裁：读者意识·语域·篇章功能｜典型失败：结构散、语域错位"]
    L1["L1 概念：观点与论据生成（2分钟3论点）｜典型失败：内容空转"]
    L2["L2 词汇/语块：搭配·介词·格支配·FVG｜典型失败：会单词组不出句"]
    L3["L3 句法：从句·语序·连接·名动转换｜典型失败：从句尾语序错、中区乱"]
    L4["L4 自动化：提取速度·自我监控｜典型失败：限时下退回A2句"]
    L5["L5 语音/书写：重音·语调·拼写｜典型失败：句子重音全平"]
  end
  subgraph SCORE["歌德 B2 评分维度"]
    E["Erfüllung 任务完成"]
    K["Kohärenz 连贯"]
    W["Wortschatz 词汇"]
    S["Strukturen 结构"]
    A["Aussprache 语音（口语）"]
  end
  L0 --> E & K
  L1 --> E
  L2 --> W
  L3 --> S & K
  L4 --> E & S
  L5 --> A
```

> [!note] 铁律：一个训练周期只压 1–2 个层
> 认知负荷理论与"专长逆转效应"表明：同时压词汇＋句法＋语篇，三者都无法程序化（自动化）。分层图的价值不在分类本身，而在**排他**——它逼你承认"这周只练 L 2＋L 3"。

## ② 证据基座：九条学习科学原理 → 出题规则

九条原理不是装饰，每一条都直接翻译成一条可检查的出题规则。左边是原理与出处，右边是它逼你做出的设计决策：

```mermaid
flowchart LR
  subgraph PRIN["九条证据基座"]
    P1["1 输出假说 Swain：产出迫使注意缺口"]
    P2["2 注意假说 Schmidt：注意是习得必要条件"]
    P3["3 技能习得三阶段 DeKeyser：陈述→程序→自动化"]
    P4["4 测试效应 Roediger/Bjork：提取＞重读"]
    P5["5 间隔＋交错 Cepeda/Rohrer"]
    P6["6 程式语优先 Wray/Boers/Wood：语块需6-10次产出性接触"]
    P7["7 聚焦反馈 Li/Kang&Han：全错纠稀释效力"]
    P8["8 提示渐退 Vygotsky/Sweller"]
    P9["9 情境干扰 Shea&Morgan：变式随机化抗遗忘"]
  end
  subgraph RULES["被逼出的出题规则"]
    R1["只出产出型任务：禁选择/判断/连线"]
    R2["目标结构必须凸显：加粗·对比·先错后讲"]
    R3["先规则意识再变式程序化：一题一点·变式成群"]
    R4["题目区与答案区分离：题干零提示·优先回忆"]
    R5["D1/D3/D7/D21 重测标记：同点跨周交错不集中刷"]
    R6["语块绑定格与介词：禁纯单词表"]
    R7["每题只标1类错码：每周期焦点≤2"]
    R8["Lv1给词→Lv2关键词→Lv3无提示"]
    R9["打乱顺序·换主题/时态/语域"]
  end
  P1 --> R1
  P2 --> R2
  P3 --> R3
  P4 --> R4
  P5 --> R5
  P6 --> R6
  P7 --> R7
  P8 --> R8
  P9 --> R9
```

> [!note] 怎么用这张图
> 验收任何一道 AI 出的题，就是反向走这张图：这题强制我产出了吗（R 1）？题干泄露答案了吗（R 4）？语块带格和介词吗（R 6）？解析是不是又全错纠了（R 7）？——任何一条断掉，这题的训练价值就显著下降。

补充一条同构框架：**产出导向法（POA，文秋芳）**的"驱动—促成—评价"与上述九条完全同构，且专为中国学习者设计——它解释了中国学习者最典型的瓶颈（输入充足、产出断裂），可直接当课型骨架。

### 三组必须记住的"为什么"

> [!tip] B 1 名动互换：得分的真正来源是"双向"
> 能把 `die Ablehnung des Antrags durch den Vorstand` 还原成 `Der Vorstand hat den Antrag abgelehnt`，才算掌握德语的信息打包机制。**名词化不是单向崇拜**——它只对学术/行政语域成立，过度名词化抬高信息密度、削弱施动关系，直接伤害 Kohärenz 得分（Wolf Schneider 的 Verbalstil 主张）。正确姿势：双向可控、按语域选择。

> [!tip] B 2 TeKaMoLo：是回退规则，不是定律
> 中区（Mittelfeld）真实排序：①代词 ＞ ②定指名词 ＞ ③不定指名词；已知信息先于新信息；TeKaMoLo 只在副词性成分**内部**套用。B 2 最容易扣分的点：**不定指宾语被推到最后**—— `Ich habe gestern in der Bibliothek ein Buch gelesen`，而不是 `…ein Buch in der Bibliothek gelesen`。

> [!tip] C 2 FVG：名词化与动词化之间的桥梁
> 功能动词结构（eine Entscheidung treffen / Kritik an etw. üben / in Frage stellen）是升级句的预制件——D 2 的升级句 90% 由语块与框架拼装而成，这就是 C 组必须先做的原因。纠错靶：`Entscheidung machen`、`Kritik machen` 这类中式直译。

## ④ 素材路由：四种输入 → 四条流水线

日常使用中，素材只有四种来源，每种走一条不同的流水线。核心盲区：**"文章"有两类，处理方向相反**——别人写的绝不能按"我的作文"批改打分。零散素材内部还要先做三桶分治：

```mermaid
flowchart TB
  IN["学习者的日常素材"] --> J{"第0步：类型判定｜判不清只许问一句，禁止猜"}
  J -->|"① 我的文章：作文/口语转录/旧文"| FA["流程A 批改流水线"]
  J -->|"② 阅读原文：新闻/范文/试题"| FB["流程B 取材流水线"]
  J -->|"③ 零散素材：勾选的词/介词/结构"| FC["流程C 三桶分治"]
  J -->|"④ 历史档案：近期多篇输出"| FD["流程D 跨文统计：错码频率→复现结构→下周期焦点"]

  FA --> A1["1 错误清单：错码分类计数｜只展开高频1-2类"]
  A1 --> A2["2 降级批改：只挑3-4处给B2替换｜禁整篇重写"]
  A2 --> A3["3 逻辑点评＋4 四维估分"]
  A3 --> BP{{"断点：停止生成｜等用户说「继续」"}}
  BP --> A5["5 高频错 → 聚焦练习题｜搭配错→诱错句；句法错→句子合并/名动互换"]

  FB --> B1["抽三类高价值项：语块 / FVG / 可借用框架"]
  B1 --> B2["标格与介词 → 直接出题｜可选：附回译材料包"]

  FC --> C0{"三桶判定（内部完成）"}
  C0 -->|"A桶 不认识"| CA["只出释义＋锚定语块条目｜不出产出题"]
  C0 -->|"B桶 认识但调不出"| CB["异主题产出题｜主战场"]
  C0 -->|"C桶 会错"| CC["聚焦纠错题｜优先诱错对比句"]

  style BP fill:#fff3cd,stroke:#bf3989,stroke-width:2px
  style CB fill:#dafbe1,stroke:#1a7f37,stroke-width:2px
```

> [!note] 为什么断点（红框）是物理必需
> LLM 是单次生成模型，没有"内部暂停"机制。不写死"执行 1–4 步后停止、等用户回复再继续"，它一定一口气把批改和出题混吐在一起。断点不是风格偏好，是对模型物理限制的工程适配。

## ⑤ 训练编排：三类日 × 21 天间隔

单个题型再好，没有编排就是随机努力。编排分两个尺度：**周内**用三类日交替（转化与输出分开），**跨周**用 21 天间隔链抗遗忘：

```mermaid
flowchart LR
  subgraph WEEK["三类日交替（周尺度）"]
    DY1["输入转化日 一三五 50分：D1延时回译 轮换焦点＋B1名动互换＋C2 FVG再造"]
    DY2["即兴输出日 二四六 50分：E1关键词阶梯复述＋B2滚雪球＋C4盲盒即兴"]
    DY3["整合模考日 周日 90分：F1整篇体裁＋F2聚焦反馈＋F3转录＋F4归档"]
    DY1 --> DY2 --> DY3 --> DY1
  end
  subgraph SPAN["21天间隔链（跨周尺度）"]
    T0["D0 首次产出"] --> T1["D+1 重说重写｜不看稿"]
    T1 --> T3["D+3 换主题｜用同框架"]
    T3 --> T7["D+7 换体裁｜用同语块"]
    T7 --> T21["D+21 限时模拟｜整套 Schreiben＋Sprechen"]
  end
  WEEK -. "每个产出物都挂上重测标记" .-> SPAN
```

```mermaid
flowchart TB
  subgraph BENCH["90分钟输出工作台（模考日展开）"]
    S0["站0 诊断 5分：同题3分钟自由说写 留稿"] --> S1["站1 解剖 15分：A1两句＋逆向造句"]
    S1 --> S2["站2 重构 10分：B1双向＋B2含不定指宾语变式"]
    S2 --> S3["站3 矿采 15分：C1五语块＋C2两FVG＋C3两框架"]
    S3 --> S4["站4 整篇 25分：F1一个B2体裁 限时"]
    S4 --> S5["站5 反馈 15分：四维自评→聚焦1-2类错→重写提交"]
    S5 --> S6["站6 归档 5分：3-5张句子级间隔卡"]
  end
```

**配比红线**：产出 60% / 输入处理 25% / 显性反馈 15%；每周期焦点 ≤2；新旧材料比 6:4。题量不能替代间隔——一周 200 题，不如三周各 40 题。

## ⑥ 反馈闭环：从诊断到重测

把全部零件组装起来，得到整个系统的总循环。**"先诊断，再配题"是唯一不能省的一步**——不知道瓶颈在哪一层，24 类题型就只是菜单而不是处方：

```mermaid
flowchart TB
  M0["诊断：口语转录 / B2作文 / 三个月前旧文 / 四层自评｜想不出内容·调不出词·句子散·限时掉档"] --> M1["定位瓶颈层 L0-L5｜确定本周期焦点 ≤2个"]
  M1 --> M2["按靶层配题｜从24类题型库选方"]
  M2 --> M3["产出：做题/写作/口头复述｜题目区零提示 强制提取"]
  M3 --> M4["聚焦反馈：只标1-2类错码｜V2/Kasus/Präp/Konnektor/Wortstellung"]
  M4 --> M5["重写提交｜反馈不落到重写=无效"]
  M5 --> M6["错误档案：我的句子/修正/我自己总结的规则"]
  M6 --> M7["句子级间隔卡 入 D1/D3/D7/D21"]
  M7 -->|"重测数据回流"| M0
  style M0 fill:#ddf4ff,stroke:#0969da,stroke-width:2px
  style M4 fill:#ffebe9,stroke:#cf222e,stroke-width:2px
```

> [!warning] 闭环上最贵的两个断点
> ① **无反馈的自由输出**＝错误固化（fossilization），练得越多错得越稳；② **反馈了但不重写**＝知道和做到之间的鸿沟没有被跨越，Li (2010) 的 d≈0.6 效应量只对"提示型＋重写"成立。这就是为什么错误档案第三列必须是"我总结的规则"——自己写规则比看讲解有效。

## ⑦ 反模式与工程陷阱

方法论的一半是"做什么"，另一半是"不做什么"。陷阱分两个世界：**教学侧**（题出错了）和**工程侧**（AI 执行崩了）。

### 教学侧反模式（明确排除）

| 反模式 | 为什么是毒 |
|---|---|
| 只做识别（多选/连线/判断） | 迁移最弱——识别≠提取，识别路径练不出产出路径 |
| 一次讲清全部语法点 | 认知过载，零程序化 |
| 无反馈的自由写作/口语重复 | 错误固化，越练越稳 |
| 纯单词表背诵 | 无搭配无格，产出时调不出来 |
| 只刷逐句翻译不做篇章规划 | Sprechen Teil 1 结构必崩 |
| 用题量替代间隔 | 一周 200 题 ＜ 三周各 40 题 |
| 每次全错纠 | 抑制输出、切碎注意力（Li 2010 / Kang & Han 2015） |
| 名词化单向崇拜 | 伤 Kohärenz；要双向可控、按语域选择 |
| TeKaMoLo 当定律背 | 真实排序是 代词＞定指＞不定指；不定指宾语靠后 |

### 工程侧陷阱（LLM 出题的实测教训）

**一句话总纲：AI 管"变式与覆盖面"，你管"提取与判断"；题目让你产出，答案永远事后对照；反馈必须落到重写；[待核] 一律人工过一遍。**
