① 句子与问题

- 原句：（本题没有原句，是词汇整理需求）
- 问题：尽可能系统、完整地收集论证论点相关的词汇，比如"赞成""反对""例如""比方说""精彩"等，涵盖对论点的拓展、延伸、态度、表态、论证、论述等所有相关表达。

② 答案

德语的论证词汇是一条流水线，按"功能位"收集最有系统：**立论**（提出论点）→ **表态**（赞成 / 反对 / 中立）→ **论证**（说明理由、推出结论）→ **举例**→ **让步与反驳**→ **拓展与延伸**→ **收尾结论**，每个位置都有专属的动词、连接词和名词。要特别注意的是，中文一个词在德语里常按搭配分成好几个："赞成"可以是 **zustimmen**（支配第三格）、**befürworten**（支配第四格）、**sich für etwas aussprechen**（**für** + 第四格）、口语的 **dafür sein**——句法各不相同，所以这些词必须"连格一起背"，只背中文意思，写出来照样是错句。同理，"反对"有 **widersprechen**（第三格）、**ablehnen**（第四格）、**sich gegen etwas aussprechen**（**gegen** + 第四格），格一错，整句就废。

另一件要分清的是语体："**Ich finde, dass ...**""**Ich bin dafür**"是口语层，能用但显得平；议论文里更得体的是 **Meiner Ansicht nach ...**、**Ich halte es für sinnvoll, dass ...**、**Es lässt sich argumentieren, dass ...** 这一档。评价词也有分工陷阱：中文的"精彩"在德语里不是一个词，而是按"哪里精彩"分家——论证严密用 **schlüssig / stichhaltig**，见解独到用 **originell / geistreich**，表达出色用 **gelungen / prägnant**，效果震撼用 **beeindruckend / brillant**，选错就会显得评价泛泛。

### **格支配速查**（写句子时的生命线）：

| 搭配 | 支配 | 例句 |
|---|---|---|
| **zustimmen** | + 第三格 | Ich stimme **dem** Vorschlag zu. |
| **widersprechen** | + 第三格 | Ich widerspreche **dem** Autor. |
| **beipflichten** | + 第三格 | Ich pflichte **ihm** bei. |
| **recht geben** | + 第三格 | Ich gebe **ihm** recht. |
| **einleuchten** | + 第三格 | Das leuchtet **mir** ein. |
| **sich anschließen** | + 第三格 | Ich schließe mich **der** Meinung an. |
| **ablehnen / befürworten / unterstützen** | + 第四格 | Ich lehne **den** Plan ab. |
| **begründen / belegen / beweisen** | + 第四格 | Das belegt **meine** These. |
| **widerlegen / entkräften / bestreiten / bezweifeln** | + 第四格 | Das widerlegt **seine** Aussage. |
| **infrage stellen** | + 第四格 | Ich stelle **das** infrage. |
| **sich aussprechen** | **für / gegen** + 第四格 | Ich spreche mich **für den** Plan aus. |
| **eintreten / plädieren** | **für** + 第四格 | Ich plädiere **für einen** Kompromiss. |

同类示例：**Ich stimme dem Autor in einem Punkt zu, lehne seine Schlussfolgerung jedoch ab.**——**zustimmen** 给第三格、**ablehnen** 给第四格，一句话里两种格各就各位；把这条规律套进上面任何一行，都成立。
