# 代副词（Pronominaladverbien / da-Komposita）讲解

## 学习目标与知识地图

学完后你应能：
1. 判断一个指代对象该用 `da(r)+介词` 还是 `介词+人称代词`（人与物/事区分）；
2. 回答“Woran / Wovon / Worauf …?”这类问句，并在口语中听懂、使用分裂形式（`Da … drauf.`）；
3. 用 `davon / darüber / darauf / daran / dazu / dafür` 准确表达“部分量、内容、对象、目的、态度”；
4. 把 `da-` 用作关联词（Korrelat），连接 `dass-/ob-/疑问从句` 与 `zu-不定式`；
5. 知道它在什么条件下**不能**使用，以及常见错误。

```
代副词
├─ ① 指代方位（具体空间）    darauf, darunter, daneben, dahinter, davor, dazwischen, darin
├─ ② 指代事物/事件/整句（抽象）damit, davon, darüber, dazu, dafür, daran, darauf, daraus, dadurch, dagegen
├─ ③ 指代人 → 基本不用，改用 介词+人称代词（mit ihm / für sie / an ihn）
├─ ④ 疑问形式                wo(r)+介词：wovon, worüber, worauf, womit, wozu, wofür, woran
├─ ⑤ 关联词功能（指后文）     darauf/daran/damit/davon + dass-/ob-从句、zu-不定式
└─ ⑥ 分裂与缩略（口语）       Da … drauf. / Da weiß ich nichts von. / drin, dran, raus
```

---

## 一、问题切入：为什么会有这种东西？

比较两组句子：

| 指代对象 | 正确 | 不能说 |
|---|---|---|
| 事物 | Ich warte **auf den Bus** → Ich warte **darauf**. | *auf es* |
| 人 | Ich warte **auf den Kollegen** → Ich warte **auf ihn**. | *darauf* |

德语里“介词后面”不能简单地放 `es` 或 `das` 来指代事物。于是把 `da`（≈“那个/这件事”）与介词融合成一个词：**da + 介词 = “介词 + 那个（事物/事件）”**。

**一句话本质：** 代副词 = 用 `da` 代替“非人的指代对象”，介词**原封不动**保留动词所要求的搭配。

**最小模型：**
```
[动词要求介词 P] + [指代对象：物/事/整句]  →  da(r) + P
[动词要求介词 P] + [指代对象：人]          →  P + 人称代词（Akk./Dat.）
```
**对应关系的局限：** `da-` 只承担“指代”，**不承担格**。`daran` 既可能是 `an + Akk.`（Ich denke daran）也可能是 `an + Dat.`（Es liegt daran / Das Bild hängt daran），要靠动词搭配判断，不能靠词形。

## 二、结构：形式规则先过一遍

**拼写规则：介词以元音开头 → `dar-`；以辅音开头 → `da-`。**

| 元音开头（dar-） | 辅音开头（da-） |
|---|---|
| daran, darauf, daraus, darin, darüber, darum, darunter, davor(例外：vor 是辅音但写作 da**vor**) | davon, damit, dazu, dafür, dadurch, dagegen, dabei, danach, daneben, dazwischen |

⚠️ 两个高频陷阱：
- **warum ≠ worum**：`warum` 问原因（为什么），`worum` 问“关于什么”（Worum geht es? / Worum bittest du?）。
- **davor / davon** 虽以辅音字母开头，都不能加 r。

## 三、分类讲解（按你要求的三类）

### A. 方位类：指代具体物品、位置

这类最常见于回答 `Wo?` / `Wohin?`，通常可以直接对译“在/到那个东西的上、下、里、旁边”。

| 代副词 | 含义 | 例句 |
|---|---|---|
| darauf | 在上面/到上面 | Der Tisch ist zu klein. Stell die Bücher **darauf**. |
| darunter | 在下面 | Das Regal? Die Kartons stehen **darunter**. |
| darin | 在里面 | Die Schachtel ist leer, es ist nichts **darin**. |
| daneben | 在旁边 | Das Museum? Die Post ist gleich **daneben**. |
| dahinter | 在后面 | Der Schrank steht an der Wand, **dahinter** ist eine Nische. |
| davor | 在前面 | Das Auto parkt **davor**. |
| dazwischen | 在之间 | Zwei Stühle und **dazwischen** ein kleiner Tisch. |
| daran | 附着于（an + Dat.） | Das Bild hängt **an der Wand**. Es hängt **daran**. |

**要点：** 方位类可以“分裂 + 缩略”，口语极常用：
- Das ist **drin**. / Da ist nichts **drin**. （= darin）
- Ich gehe **rauf / rein / raus / rüber**. 
- Der Aufkleber ist **dran**. （= daran，也引申为“轮到…了”：Du bist dran!）

**边界：** 如果只是“在那儿”，不需要介词，用 `dort / da / hier`：*Wo ist der Schlüssel? — Da liegt er.* 只有动词或名词本身要求介词时才用 `da(r)+P`：*Woran hängt das Bild? — Es hängt an der Wand / daran.*

---

### B. 指代事物、事件、整句（抽象类）

这是 B2/C1 的主战场，考察的是**动介搭配**。

| 代副词 | 典型搭配（动/名 + 介词） | 例句 |
|---|---|---|
| **davon** | von + Dat.：abhängen, ausgehen, träumen, sprechen, leben, überzeugt sein, hören, keine Ahnung haben | Das hängt **davon** ab, ob er Zeit hat. |
| **darüber** | über + Akk.：sprechen, nachdenken, sich freuen, sich ärgern, diskutieren, informieren | Ich habe lange **darüber** nachgedacht. |
| **darauf** | auf + Akk.：warten, sich freuen, sich verlassen, achten, hoffen, hinweisen | Du kannst dich **darauf** verlassen. |
| **daran** | an + Akk./Dat.：denken, arbeiten, zweifeln, sich erinnern, liegen, teilnehmen | Ich arbeite **daran**, mein Deutsch zu verbessern. |
| **dazu** | zu + Dat.：raten, gehören, kommen, führen, brauchen, einladen | **Dazu** kommt, dass die Mieten steigen. |
| **dafür** | für + Akk.：sich interessieren, sprechen, halten, danken, sorgen, sein (=赞同) | Ich bin **dafür**. / Was spricht **dafür**? |
| **dagegen** | gegen + Akk.：sein, protestieren, sich wehren, sprechen | Ich bin **dagegen**, dass man das Gesetz ändert. |
| **damit** | mit + Dat.：rechnen, anfangen, aufhören, sich beschäftigen, meinen, zufrieden sein | Hast du **damit** gerechnet? |
| **daraus** | aus + Dat.：folgen, schließen, lernen, machen | **Daraus** folgt, dass wir mehr Zeit brauchen. |
| **dadurch** | durch + Akk.：erreichen, entstehen, verursachen | **Dadurch**, dass er täglich übt, wird er sicherer. |
| **dabei** | bei + Dat.：helfen, sein, bleiben, sich fühlen, stören | Ich habe ihm geholfen. **Dabei** habe ich viel gelernt. |

**注意 `damit` 的双重身份**（高频歧义点）：
- 代副词：*Ich nehme den Bus und fahre **damit** zur Arbeit.*（= mit dem Bus）
- 连词“为了”：*Ich spreche langsam, **damit** du mich verstehst.*（从句，动词居末）

判断方法：后面跟的是从句（动词末位）→ 连词；否则是代副词。

### C. 指代人：原则与两个例外

**基本原则：`da(r)+P` 指人 = 错误。** 用 `介词 + 人称代词`。

| 误 | 正 |
|---|---|
| *Ich warte darauf*（指同事） | Ich warte **auf ihn**. |
| *Ich habe davon gehört*（指某人） | Ich habe **von ihm** gehört. |
| *Ich interessiere mich dafür*（指某人） | Ich interessiere mich **für sie**. |
| *Wovon träumst du?*（指人） | **Von wem** träumst du? |

**例外 1：群体中的一部分（部分量）——`davon` 可以指人**
> Zehn Teilnehmer, **davon** fünf Frauen. （十名参加者，其中五名女性）
> Ich habe viele Freunde, aber nur wenige **davon** sehe ich regelmäßig.
这里 `davon` 指的不是“某个具体的人”，而是“整体中的部分”，所以不算违规。

**例外 2：拟人化/机构化对象**（同为物化处理）
> Die Regierung? Ich bin **davon** überzeugt, dass …（把政府当“事态”看待，可接受；但强调具体的人时仍用 `von ihr`。）

**补充：`es` 与它无关。** `es` 是占位/回指代词，不表示“介词+它”：
> Ich weiß **es**.（我知道那件事）/ Ich weiß **davon**.（我有耳闻，语感更“听说/了解一点”）

---

### D. 疑问词：wo(r) + 介词（重点展开）

**规则：问“事物/事件”用 `wo(r)+P`；问“人”用 `介词 + wen/wem`。** 这是 100% 可操作的判定标准。

| 动词搭配 | 问事物 | 问人 |
|---|---|---|
| warten auf | **Worauf** wartest du? | **Auf wen** wartest du? |
| denken an | **Woran** denkst du? | **An wen** denkst du? |
| sich ärgern über | **Worüber** ärgerst du dich? | **Über wen** ärgerst du dich? |
| sprechen von | **Wovon** sprichst du? | **Von wem** sprichst du? |
| sich interessieren für | **Wofür** interessierst du dich? | **Für wen** interessierst du dich? |
| Angst haben vor | **Wovor** hast du Angst? | **Vor wem** hast du Angst? |
| abhängen von | **Wovon** hängt das ab? | **Von wem** hängt das ab? |
| sich beschäftigen mit | **Womit** beschäftigst du dich? | **Mit wem** …? |
| bitten um | **Worum** bittest du? | **Um wen** bittest du? |
| gehören zu | **Wozu** gehört das? | **Zu wem** gehört das? |

**三条附加规则：**

1. **`wo` 单独使用**问地点（无介词）：*Wo wohnst du?* 一旦动词要求介词，就必须 `wo(r)+P`：*Woran erkennst du das?*（不能 *Wo erkennst du das an?*）

2. **`was` + 介词 = 口语/非正式**：*Auf was wartest du? / Über was sprichst du?* 在口语中常见，歌德 B2/C1 写作与正式口语请用 `worauf / worüber`。

3. **`warum / weshalb / wieso` 与 `worum` 严格区分**：
   - *Worum geht es?*（讨论的主题是什么）
   - *Warum geht es nicht?*（为什么不顺利）

**典型考题形态（信息提取 → 提问）**：
> Er hat sich über das Wetter geärgert. → **Worüber** hat er sich geärgert?
> Sie hat mit ihrer Chefin gesprochen. → **Mit wem** hat sie gesprochen?

## 四、机制深挖：`davon` 的六种语义

`davon` 使用频率极高，但它不止一个意思，学习者常因“只记一个义项”而在写作中选错。请按语义网络记：

| 义项 | 解释 | 例句 |
|---|---|---|
| ① 来源/依据 | von + Dat.，“取决于、源于” | Das hängt ganz **davon** ab, wie viel Zeit wir haben. / Das kommt **davon**!（都是这样惹的祸！） |
| ② 内容/话题 | “关于这点” | Ich habe **davon** gehört. / **Davon** habe ich keine Ahnung. / Was hältst du **davon**? |
| ③ 部分量（partitiv） | “其中（多少）” | Zwanzig Bewerber, **davon** zehn aus dem Ausland. / Möchtest du Kuchen? — Ja, gern ein Stück **davon**. |
| ④ 空间分离（少见） | “从那儿离开” | Der Zug fährt **davon**.（更常说 *weg*） |
| ⑤ 固定短语（C1 连接词） | **abgesehen davon**（除此之外）/ **davon abgesehen, dass** | **Abgesehen davon**, dass es teuer ist, ist die Lage ideal. |
| ⑥ 脱离/恢复 | sich erholen von, befreien von | Er muss sich **davon** erst erholen. |

**`davon` vs `darüber` vs `daraus`：三个易混边界**

| | 核心义 | 例句 |
|---|---|---|
| davon | 来源/内容（“关于它、从它那儿”） | Wir haben **davon** gesprochen, wie man Kosten senkt.（谈了这个内容） |
| darüber | 主题（“围绕它讨论/思考”） | Wir haben lange **darüber** diskutiert. |
| daraus | 由其中产生（结果、推论） | **Daraus** folgt, dass … / Was machst du **daraus**? / **Daraus** wird nichts. |

也就是说：`von` 搭配 → `davon`；`über` 搭配（讨论/情绪/思考）→ `darüber`；`aus` 搭配（来源→产物）→ `daraus`。**不要按中文语感猜，按动词搭配“背”。**

## 五、关联词功能：指向后文的 `da-`（B2→C1 关键）

这类 `da-` 不指前文，而是**预告后面的从句或不定式**，德语叫 Korrelat。

| 类型 | 结构 | 例句 |
|---|---|---|
| + dass-从句 | darauf, daran, damit, davon, dafür, dagegen, darüber | Ich freue mich **darauf**, dass du kommst. / Ich zweifle **daran**, dass das stimmt. / Er hat **damit** gerechnet, dass es teuer wird. / Ich bin **davon** überzeugt, dass … |
| + ob-从句 | davon, darauf | Es hängt **davon** ab, **ob** er zusagt. |
| + 疑问从句 | daran, darauf, davon | Ich habe keine Ahnung **davon**, **wann** er kommt. |
| + zu-不定式 | darauf, daran, damit, dazu | Ich freue mich **darauf**, dich zu sehen. / Ich arbeite **daran**, pünktlicher zu sein. / Er hat **dazu** geraten, zu warten. |

**判定方法（非常实用）：** 动词/名词搭配的介词决定 da- 的形式；`dass/ob/zu` 从句提供“内容”。所以：
```
sich freuen auf + Akk.  →  darauf + zu-Inf. / dass-Satz
zweifeln an + Dat.     →  daran  + dass-Satz
abhängen von + Dat.    →  davon  + ob-Satz
```
⚠️ 不能把介词直接留在从句前：*Ich freue mich auf, dass …* ✗ → 必须 `darauf, dass …`。

## 六、句法与语用细节

1. **可重读、可前置**：*DAVON habe ich nichts gewusst.*（强调“这一点”）
2. **分裂形式（口语必须能听懂）**：
   - *Da kannst du dich **drauf** verlassen.*（= darauf）
   - *Da weiß ich nichts **von**.*
   - *Da habe ich keine Lust **zu**. / Da freue ich mich **drauf**.*
   这类句子在 B2 听力中非常常见：`da` 在前场，介词留在句末。
3. **缩略形**：drauf, dran, drin, drüber, drunter, rauf, rein, raus, rüber。写作中除引用口语外避免。
4. **`daran` ≠ 关系代词**：指代具体名词时用关系代词并保持性数格一致：
   - *Das Buch, **an dem** ich arbeite, …*（名词性先行词 → 关系代词）
   - *Ich arbeite **daran**, ein Buch zu schreiben.*（整件事/行为 → 代副词）

## 七、实战任务（含判断标准与纠错）

**任务：把下列句中加粗成分改写成代副词形式；若指人则改写为人称代词。**

1. Warten Sie auf **den Bus**? 
2. Warten Sie auf **den Busfahrer**?
3. Hast du von **dem Unfall** gehört?
4. Hast du von **deinem Lehrer** gehört?
5. Sie interessiert sich für **Politik**.
6. Sie interessiert sich für **ihren Nachbarn**.
7. Er hat sich über **das Ergebnis** geärgert.
8. Ich denke oft an **meine Kindheit**.
9. Er hat mit **dem Projekt** angefangen.
10. Wir sprechen über **die neue Regelung**.

**答案与判断依据**

1. Warten Sie **darauf**?（事物 → da-，auf + Akk.）
2. Warten Sie **auf ihn**?（人 → 介词 + 人称代词）
3. Hast du **davon** gehört?（von + Dat. 事件）
4. Hast du **von ihm** gehört?（人）
5. Sie interessiert sich **dafür**.（für + Akk. 事物）
6. Sie interessiert sich **für ihn**.（人）
7. Er hat sich **darüber** geärgert.（sich ärgern über）
8. Ich denke oft **daran**.（denken an）
9. Er hat **damit** angefangen.（anfangen mit）
10. Wir sprechen **darüber**.（sprechen über；若强调“谈到了这个内容”也可 **davon**，语感更偏“提到/听说”）

**评分标准（自测用）：**
- 形式正确（da-/dar- 拼写、介词与动词搭配一致）：各 1 分；
- 人与物区分正确：漏一处即为“搭配未内化”，需回背该动词；
- 若写成 `*auf es / *für es / *von das`，说明仍在用“介词+es”，需重做本组题。

**高频错误 → 正确做法**

| 常见错误 | 原因 | 正确 |
|---|---|---|
| *Ich habe Angst davon.* | 记错介词 | Angst **vor** → **davor** |
| *Ich freue mich für das.* | 中文“为…高兴”直译 | sich freuen **auf/über** → **darauf/darüber** |
| *Wovon träumst du?*（指人） | 未做人物判断 | **Von wem** träumst du? |
| *Ich freue mich auf, dass …* | 关联词缺失 | **darauf**, dass … |
| *Worum geht es dir? / Warum geht es dir?* 混用 | warum=原因，worum=主题 | *Worum geht es?* / *Warum geht es dir schlecht?* |
| *Ich interessiere mich dafür Politik.* | 介词残留 | **dafür**（不加介词）；名词则用 *für Politik* |

## 八、边界：什么时候不能用

1. **不能构成代副词的介词**：`ohne, statt, wegen, trotz, während, seit, außer, gegenüber, innerhalb, aufgrund` 等（多为二格/三格支配或无固定搭配）。此时用 `介词 + 代词/名词`：*ohne ihn, trotz des Regens*。问句也不能说 *worohne*。
2. **指人时不可（部分量除外）**：见第三部分。
3. **指代具体名词做关系从句时不可**：需用关系代词（*die Firma, **für die** ich arbeite*）。
4. **方位类不能滥用**：若动词不要求介词，用 `da/dort/hier`。*Wo ist Tom? — *Da* (nicht „daran“).*
5. **`davon` 不等于“所有 von 结构”**：`von + 人名` 永远 `von ihm/ihr`；`von + 抽象事` 才 `davon`。
6. **`damit` 与 `dass`/`um … zu` 的选择**：目的从句同主语可用 `um … zu`，不同主语用 `damit`；这与代副词 `damit` 无关，必须区分。

## 九、回扣开篇与可迁移模型

我们开头的问题是：**德语为什么需要一个“da+介词”的词？** 答案是：因为德语的介词必须带一个“名词性成分”，而 `es/das` 不能承担“介词宾语指代事物”的功能；`da(r)+P` 就是为这个空位设计的**代词化介词**。它同时承担三种角色——**回指（anaphorisch）、预告（kataphorisch）、提问（wo-）**——这就是它能贯穿方位、抽象事态与从句连接的原因。

**可迁移的四步判断树（背下来就能用）：**

```
① 指代对象是人（个体）吗？
   是 → 介词 + 人称代词（Frage: 介词 + wen/wem）
   否 ↓
② 动词/名词要求哪个介词？（搭配表）
   ↓
③ 问句？
   是 → wo(r) + 介词（介词以元音开头加 r）
   否 ↓
④ 指前文还是后文？
   前文 → da(r) + 介词（可分裂：Da … drauf.）
   后文（dass/ob/W-从句、zu-Inf.）→ da(r) + 介词作关联词
```

**最后一条学习建议（可执行）：** 建一张“动词—介词—代副词”三列卡片，每遇到一个动介搭配就补一行（abhängen – von – davon；sich ärgern – über – darüber …）。代副词不是靠规则推出来的，而是靠**搭配记忆 + 人/物判断**两条腿走路；规则只负责“形式和位置”，搭配负责“选哪个”。
