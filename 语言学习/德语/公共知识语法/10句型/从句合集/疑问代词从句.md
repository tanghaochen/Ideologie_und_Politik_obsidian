# 疑问代词从句（W-从句 / indirekter Fragesatz）完全指南

## 0. 术语澄清：先分清"三种形式相同的 W-从句"

德语中以 W-词开头的从句，**表面形式相同，语法功能却是三类完全不同的东西**。这是中国学生最大的陷阱，必须先分清：

| 类别                 | 德语术语                                      | 判定特征                                               | 例                                            |
| ------------------ | ----------------------------------------- | -------------------------------------------------- | -------------------------------------------- |
| ① **间接疑问从句**（本讲主角） | W-Interrogativsatz / eingebettete Frage   | 从句内容是"一个问句内容"（可还原为直接问句）；**没有先行词**；有"未知信息槽位"        | Ich weiß nicht, **wer** das war.             |
| ② **自由关系从句**（含概括义） | freier Relativsatz                        | W-词是**关系代词**，可改写成 derjenige, der / das, was；无"提问"义 | **Wer** zuletzt lacht, lacht am besten.      |
| ③ **概括让步从句**       | verallgemeinernde Konzessiv-/Relativsätze | 形式为 W + auch (immer)，表"无论……都……"                    | **Wer** auch immer anruft, ich bin nicht da. |

**"疑问代词从句"狭义**指①中由 **Interrogativpronomen（wer, was, welcher, was für ein）**引导的从句；**广义/教学常用**涵盖①中由疑问词引导的全部 W-从句，包括疑问副词（wo, wann, wie, warum…）和疑问代副词（wo(r)+介词）。
下文两者都讲，凡涉及"代词 vs 副词"差异处会明确标注。

上位概念：**间接疑问句（indirekte Fragesätze）**有两类——
- **W-Fragesatz**：由疑问代词、疑问副词、疑问代副词引导（本讲）；
- **ob-Satz**：由 ob 引导的是/否疑问（只作对照，见 §7.2）。

## 1. 核心定义、形成原因与使用条件

### 1.1 定义

疑问代词从句 = **用一个"嵌入的问句"充当主句的一个句法成分**（主语、宾语、介词宾语、表语、名词后的同位性内容）的从句；语义上它表示主句谓词所涉及的**一个信息空位（Wissenslücke）或问题答案**。

### 1.2 形成原因（功能动因 + 结构动因）

1. **功能动因**：人需要"转述别人提出的问题"和"表达自己知道/不知道某个答案"这种认知状态。直接问句（Wer ist das?）**不能**直接做另一个句子的成分，所以必须"从句化"嵌入，产生间接疑问从句。
2. **结构动因**：德语从属句使用**框架结构（Satzklammer）**——引导词占"左括号"，变位动词占"右括号"（尾语序）。W-词天然占据左括号位置，因为它在句内**本身就是一个句法成分**（提问焦点），同时兼任"连接词"。
3. **对比**：英语有同类结构（I wonder who he is），但英语疑问从句不标记格；中文既无格也无尾语序（"我不知道他是谁"）。所以中文母语者既要适应**尾语序**，又要学会在 **wer/wen/wem/wessen** 之间按**从句内功能**选格。

### 1.3 三条使用条件（缺一不可）

1. **从句内容 = 一个问句内容**：能还原成直接问句（Wer…? Was…? Welcher…? Wo…? Wann…? Wie…? Warum…? Wie viel…?）。
2. **主句谓词属于下列语义场**：知识/信息、提问、告知、思考、记忆、依赖、评价（§4 穷举）。
3. **没有先行词**：如果前文有名词/代词让从句去修饰、限定，那就是关系从句，不是疑问从句（§7.3，本讲重点）。

**典型例（含逐词解析）**

- **Ich weiß nicht, wer das gesagt hat.** 我不知道这话是谁说的。
  解析：ich=主句主语｜weiß=主句谓语(V 2)｜nicht=否定｜wer=疑问代词，从句**主语（第一格）**｜das=从句宾语｜gesagt hat=从句谓语（尾语序，完成时框型）。
- **Weißt du, wann der Zug fährt?** 你知道火车什么时候开吗？
  解析：weißt=主句谓语(V 2)｜du=主语｜wann=疑问副词，从句引导｜der Zug=从句主语｜fährt=从句谓语（尾语序）｜标点由**主句**是问句决定。

### 1.4 适用的场景 vs 不适用的场景

**适用**：转述提问、礼貌询问、表示知道/不知道答案、表达好奇与评价、决定/计划、调查查明、记忆遗忘、依赖条件（详见 §5）。

**不适用**：
- 从句修饰一个已知名词/代词 → **关系从句**；
- 表达一个完整命题（当作事实） → **dass**；
- 表达是/否（真值未知） → **ob**；
- 表达时间/条件/原因/让步/目的/方式等"情形" → **状语从句**（als, wenn, weil, obwohl, damit, indem…）；
- "无论谁/什么……" → **W + auch (immer)** 引导的让步/概括结构；
- 主句谓词是 glauben, hoffen, behaupten, meinen, bedauern 等**纯命题态度词** → 只能接 dass，不能接 W-从句（§8 有纠正）。

## 2. 构造规则：公式、语序、标点

### 2.1 基本公式

**主句 + 逗号 + ［W-成分 + 其余成分 + 变位动词（末位）］**

W-成分可以是一个词，也可以是一个词组：*mit wem, auf wen, was für ein Auto, seit wann, wie viele Leute*。

### 2.2 直接问句 → 间接问句：唯一转换公式

| 直接问句（V 2，问号） | 间接疑问从句（V-final，无问号） |
|---|---|
| Wer ist das? | Ich weiß nicht, **wer das ist**. |
| Was willst du? | Sag mir, **was du willst**. |
| Wen hast du gesehen? | Er fragte, **wen ich gesehen habe**. |
| Wem hast du geholfen? | Ich weiß nicht, **wem er geholfen hat**. |
| Wessen Auto ist das? | Ich weiß nicht, **wessen Auto das ist**. |
| Welchen Zug nimmst du? | Ich weiß nicht, **welchen Zug ich nehmen soll**. |
| Was für ein Haus ist das? | Ich weiß nicht, **was für ein Haus das ist**. |
| Wo arbeitest du? | Er fragt, **wo ich arbeite**. |
| Wohin fährst du? | Ich weiß nicht, **wohin er fährt**. |
| Woher kommst du? | Darf ich fragen, **woher Sie kommen**? |
| Wann beginnt der Kurs? | Wissen Sie, **wann der Kurs beginnt**? |
| Warum lachst du? | Ich verstehe nicht, **warum du lachst**. |
| Wie heißt du? | Ich habe vergessen, **wie er heißt**. |
| Wie viel kostet das? | Ich weiß nicht, **wie viel das kostet**. |
| Kommt er?（是/否问句） | Ich weiß nicht, **ob er kommt**. |

**唯一改动**：变位动词从第二位（V 2）搬到**从句末位**；W-词本身**不变形**（格由它在从句内的功能决定，见 §3.1）。

### 2.3 语序细节（穷举）

1. **尾语序是硬规则**：W-成分占从句左括号位，**其他任何成分不得移到 W-词前面**，也不能出现 V 2。
   - ✗ *Ich weiß nicht, das Buch wer gelesen hat.* → ✓ **Ich weiß nicht, wer das Buch gelesen hat.** 我不知道谁读了这个书。
2. **情态动词 / 完成时 / 被动 / 将来**：所有动词性成分全部靠后。
   - ✓ **Weißt du, wie ich das machen kann?** 你知道我怎么做这件事吗？（kann 在最后）
   - ✓ **Ich weiß nicht, wen sie gesehen hat.** 我不知道她看见了谁。
   - ✓ **Ich weiß nicht, wie das gemacht wird.** 我不知道这是怎么做的（被动）。
   - ✓ **Ich weiß nicht, wann er kommen wird.** 我不知道他什么时候会来。
3. **可分动词**：从句中前缀与动词**重新合并**、整体靠后。
   - ✗ *Ich weiß nicht, wann kommt er an.* → ✓ **Ich weiß nicht, wann er ankommt.** 我不知道他什么时候到。
   - ✓ **Ich weiß nicht, wo er herkommt.** 我不知道他是哪儿的人。
   - ✓ **Ich weiß nicht, wann er aufstehen muss.** 我不知道他得什么时候起床。
   - 进阶：完成时+情态动词用 **Ersatzinfinitiv**：**Ich weiß nicht, wie er das hätte machen sollen.** 我不知道他当时该怎么做这件事。
4. **多个 W-成分**（"谁给谁什么"）：按主—三—四（Nom–Dat–Akk）排列。
   - ✓ **Ich weiß nicht, wer wem was geschenkt hat.** 我不知道谁送给了谁什么。
5. **从句内部其他成分语序**：与普通从句一致（TeKaMoLo：时间—原因—方式—地点）。
   - ✓ **Ich weiß nicht, wann er morgen mit dem Auto nach Berlin fährt.** 我不知道他明天什么时候开车去柏林。
6. **否定词位置**：按普通从句规则，放在被否定成分前。
   - **Ich weiß nicht, warum er das Buch nicht gelesen hat.** 我不知道他为什么没读这本书。（≠ **Ich weiß, warum er das Buch nicht gelesen hat.** 我知道他为什么没读这本书。）
7. **关联词（Korrelat）行为**：
   - 主语从句外置时，"es" 作**先行词**（必需）：**Es ist unklar, wer das war.** 那是谁还不清楚。
   - "finden + es + 形容词"结构中 "es" 也是关联词：**Ich finde es traurig, wie schnell das vergessen wird.** 我觉得这么快就被遗忘很可悲。
   - 介词性关联词（darauf, darüber, daran）常出现、也可省略：**Ich bin gespannt (darauf), wie das ausgeht.** 我很期待结果会怎样。
   - 与 dass-/ob-从句不同，直接作 wissen/sagen 宾语的 W-从句**通常不带 es**：✓ **Ich weiß nicht, wo er wohnt.** 口语可听到 "Ich weiß es nicht, wo er wohnt"，属口语/强调变体。
1. **从句前置（Vorfeld）**：整个从句可提到主句句首，此时主句**倒装**（V 2），且不用 es。
   - ✓ **Wo er wohnt, weiß ich nicht.** 他住哪儿，我不知道。
   - ✓ **Wen er meint, ist mir klar.** 他指谁，我清楚。
   - ✗ *Wo er wohnt, ich weiß nicht.*（主句未倒装）
9. **多层嵌套**：
   - **Ich weiß nicht, ob sie weiß, wo er wohnt.** 我不知道她是否知道他住在哪儿。

### 2.4 标点与语气：由**主句**决定

| 主句句型 | 标点 | 例 |
|---|---|---|
| 陈述句 | 句号 | **Er fragte, wo ich wohne.** 他问我住在哪儿。 |
| 问句 | 问号（全句只在末尾一个） | **Weißt du, wann er kommt?** 你知道他什么时候来吗？ |
| 祈使句 | 叹号 | **Sag mir, wo du bist!** 告诉我你在哪儿！ |
| 直接引语 | 冒号+引号 | **Er fragte: „Wo wohnst du?“** 他问："你住哪儿？" |

- 问号**只有一个**：✗ *Ich weiß nicht, wann er kommt?*（主句是陈述句→句号）。
- 间接疑问从句**没有升调、没有问号**，但它承载"问题内容"——这正是"间接"的含义。

## 3. 疑问代词完整词表与变格

### 3.1 wer / was（人 / 物·事态）

| Kasus | wer（人） | was（物、事态） |
|---|---|---|
| Nominativ | **wer** | **was** |
| Genitiv | **wessen** | **wessen**（罕用、书面） |
| Dativ | **wem** | **—（无形式！）** |
| Akkusativ | **wen** | **was** |

**用法说明（逐条）**

1. **格 = 它在从句内的功能**，与主句动词的支配**无关**：
   - **Ich weiß nicht, wer kommt.** 我不知道谁会来。（从句主语→第一格）
   - **Ich weiß nicht, wen du meinst.** 我不知道你指谁。（从句第四格宾语）
   - **Ich weiß nicht, wem sie hilft.** 我不知道她在帮谁。（从句第三格宾语）
   - **Ich weiß nicht, wessen Auto das ist.** 我不知道这是谁的车。（第二格定语）
   - 对比主句动词的宾语：**Ich frage ihn, wen er meint.** 我问他，他指的是谁。（ihn=fragen 的第四格宾语；wen=从句内第四格，两者互不影响）
2. **was 没有第三格**。指物的第三格宾语只能改写或用 wo(r)-：
   - ✗ *Ich weiß nicht, was ich das verdanke.* → ✓ **Ich weiß nicht, wozu ich das verdanke.** / ✓ **Ich weiß nicht, wem ich das verdanke.**（后句指人）
   - 规律：**wem 只指人**；指物时用 wo(r)+介词 或换说法（Wozu…? Wofür…? Womit…?）。
3. **wessen 极书面/极少**，口语优先改写：
   - **Ich weiß nicht, wessen Tasche das ist.**（书面）＝ **Ich weiß nicht, wem die Tasche gehört.** 我不知道这包是谁的。
   - 第二格宾语更罕见：**Ich weiß nicht, wessen er sich rühmt.** 我不知道他自夸什么。（sich einer Sache rühmen，极书面）
4. **人物区分**：问**人（身份）**用 wer，问**物/事态**用 was；问职业用 was。
   - **Wer ist diese Frau？** 这位女士是谁？——**Das ist meine Chefin.** 是我的上司。
   - **Was ist er von Beruf？** 他职业是什么？——**Er ist Arzt.** 他是医生。
5. **口语扩展**：wer alles / was alles（口试："Ich weiß nicht, wer alles kommt." 我不知道都会来哪些人）。

### 3.2 welcher（"哪一个"，从已知集合中选择）

疑问代词/疑问冠词双重身份；**性、数与从句内的名词一致**（这是与 wer/was 的重要差别）。

| Kasus | Maskulin | Feminin | Neutrum | Plural |
|---|---|---|---|---|
| Nominativ | welcher | welche | welches | welche |
| Genitiv | welches | welcher | welches | welcher |
| Dativ | welchem | welcher | welchem | welchen |
| Akkusativ | welchen | welche | welches | welche |

- 作定语：**Ich weiß nicht, welchen Zug ich nehmen soll.** 我不知道该坐哪趟车。（welchen 与 Zug：阳性第四格）
- 名词性用法：**Ich weiß nicht, welchen du meinst.** 我不知道你指哪一个。／**Welcher der beiden Züge ist schneller？** 两趟车哪趟更快？
- 第二格几乎不用（学会识别即可）。
- **welcher 的另一身份**：关系代词（书面、生硬，可换成 der/die/das）——**Der Zeuge, welcher den Unfall sah, sagte aus.** 目睹事故的证人作了陈述。这与疑问 welcher 形式相同、功能不同（见 §7.3）。
- **welcher（选择）vs wer（身份）**：从已知集合选 → welcher；身份未知 → wer。
  - **Ich weiß nicht, welcher meiner Kollegen das war.** 我不知道是我哪个同事干的。（有集合"我的同事们"）
  - **Ich weiß nicht, wer das war.** 我不知道那是谁。（无集合，纯身份）

### 3.3 was für ein（"什么样的"，问种类/性质）

只有 **ein** 变格；**was** 和 **für** 不变；复数无冠词。

| Kasus | Maskulin | Feminin | Neutrum | Plural |
|---|---|---|---|---|
| Nominativ | was für ein | was für eine | was für ein | was für (Männer) |
| Genitiv | was für eines | was für einer | was für eines | —（极少，改写） |
| Dativ | was für einem | was für einer | was für einem | was für (Leuten) |
| Akkusativ | was für einen | was für eine | was für ein | was für (Männer) |

- **Ich weiß nicht, was für ein Auto er fährt.** 我不知道他开什么样的车。
- **分裂式**（常见）：**Ich weiß nicht, was das für ein Auto ist.** 我不知道那是什么样的车。
- 复数：✓ **Was für Bücher liest du？** ✗ *Was für ein Bücher…*
- **welcher（选择）vs was für ein（种类）**：
  - **Ich weiß nicht, welchen Wein ich kaufen soll.**（从酒单上选一瓶）
  - **Ich weiß nicht, was für einen Wein ich kaufen soll.**（要买哪种类型的酒）
- **绝不能引导关系从句**：✗ *Das Auto, was für ein er fährt, …* → ✓ **Das Auto, das er fährt, …** 他开的那辆车……
- **"was für" ≠ "für was"**：was für=种类；für was 是口语的 "wofür"（✗标准）。✓ **Wofür ist das gut？** 这有什么用？（口语：Für was ist das gut？）

### 3.4 疑问副词与疑问代副词（同属 W-从句家族）

**疑问副词清单**

| W-词 | 询问 | 间接从句例 |
|---|---|---|
| wo | 地点（静态） | Ich weiß nicht, **wo** er wohnt. 我不知道他住哪儿。 |
| wohin | 方向 | Ich weiß nicht, **wohin** er gefahren ist. 我不知道他去哪儿了。 |
| woher | 来源 | Weißt du, **woher** sie kommt？ 你知道她从哪儿来吗？ |
| wann | 时间点 | Wissen Sie, **wann** der Kurs beginnt？ |
| seit wann / bis wann / ab wann | 起止时间 | Ich weiß nicht, **seit wann** er hier arbeitet. |
| wie lange / wie oft / wie weit | 时长/频率/距离 | Ich weiß nicht, **wie lange** das dauert. |
| wie | 方式、性质、名称、程度 | Ich weiß nicht, **wie** er heißt.（名字用 wie！） |
| wie viel / wie viele | 数量（不可数/可数复数） | Ich weiß nicht, **wie viel** Zeit wir haben. / …**wie viele** Leute kommen. |
| warum / wieso / weshalb / weswegen | 原因 | Ich weiß nicht, **warum** er das getan hat. |
| wozu / wofür / womit / wodurch … | 目的、工具、方式等 | Ich weiß nicht, **wozu** das gut sein soll. |
| inwiefern / inwieweit | 程度、范围 | Unklar ist, **inwieweit** das stimmt. |

**语体差异**：warum 中性通用｜**wieso** 口语、常带困惑或惊讶｜**weshalb** 偏正式/书面｜**weswegen** 使用频率低、偏口语。四者语法上可互换。

**书写**：标准写法是分开的 **wie viel / wie viele**（"wieviel"为旧式）。序数："das **wievielte** Mal"（第几次）。

**疑问代副词 wo(r)+介词**——询问"介词宾语（物）"

| 介词 | 代副词 | 例 |
|---|---|---|
| an | woran | Ich weiß nicht, **woran** er denkt. 我不知道他在想什么。 |
| auf | worauf | Ich weiß nicht, **worauf** er wartet. 我不知道他在等什么。 |
| aus | woraus | Ich weiß nicht, **woraus** das besteht. 我不知道这由什么构成。 |
| bei | wobei | Ich weiß nicht, **wobei** ich helfen kann. 我不知道能帮上什么。 |
| durch | wodurch | Ich weiß nicht, **wodurch** das passiert ist. 我不知道这是由什么引起的。 |
| für | wofür | Ich weiß nicht, **wofür** das gut ist. 我不知道这有什么用。 |
| gegen | wogegen | Ich weiß nicht, **wogegen** er protestiert. 我不知道他抗议什么。 |
| hinter | wohinter | Ich weiß nicht, **wohinter** er sich versteckt.（少） |
| in | worin | Ich weiß nicht, **worin** der Unterschied liegt. 我不知道区别在哪儿。 |
| mit | womit | Ich weiß nicht, **womit** er das bezahlt hat. 我不知道他用什么付的钱。 |
| nach | wonach | Ich weiß nicht, **wonach** er sucht. 我不知道他在找什么。 |
| über | worüber | Ich weiß nicht, **worüber** sie sich unterhalten. 我不知道他们在聊什么。 |
| um | worum | Ich weiß nicht, **worum** es geht. 我不知道事关什么。 |
| unter | worunter | Ich weiß nicht, **worunter** er leidet. 我不知道他受什么折磨。 |
| von | wovon | Ich weiß nicht, **wovon** er träumt. 我不知道他梦想什么。 |
| vor | wovor | Ich weiß nicht, **wovor** er Angst hat. 我不知道他怕什么。 |
| zu | wozu | Ich weiß nicht, **wozu** das gut sein soll. |
| zwischen | wozwischen | Ich weiß nicht, **wozwischen** der Unterschied liegt.（极少） |

**构词规则**：介词以**元音**开头时插入 -r-：wor**an**, wor**auf**, wor**aus**, wor**in**, wor**über**, wor**um**, wor**unter**；辅音开头不加：wo**bei**, wo**durch**, wo**für**, wo**gegen**, wo**mit**, wo**nach**, wo**von**, wo**vor**, wo**zu**。

**人物 vs 事物**（核心选择规则）：
- 事物/事态 → **wo(r)+介词**：**Ich weiß nicht, worauf er wartet.**
- 人 → **介词 + wen/wem**：**Ich weiß nicht, auf wen er wartet.** 我不知道他在等谁。（auf+Akk→wen）
- **Ich weiß nicht, mit wem er spricht.** 我不知道他在跟谁说话。（mit+Dat→wem）
- 口语变体 "auf was / mit was / über was"（非正式；书面用 worauf/womit/worüber）。

### 3.5 形式相同但**不是**疑问的结构（预警表）

| 形式 | 实际身份 | 例 | 判定 |
|---|---|---|---|
| was | 关系代词（先行词为 alles/etwas/nichts/das Beste…，或指代整句） | **Alles, was du sagst, stimmt.** 你说的一切都对。／**Er kam zu spät, was mich ärgerte.** 他迟到了，这让我很恼火。 | 能换成 das → 关系 |
| wer | 自由关系（=derjenige, der） | **Wer zuletzt lacht, lacht am besten.** 笑到最后的人笑得最好。 | 能改写 derjenige, der → 关系 |
| welcher | 关系代词（书面） | **Der Zeuge, welcher den Unfall sah, …** | 能换成 der → 关系 |
| wo | 关系词（口语，地点/时间） | **Die Stadt, wo ich geboren bin, …** | 能换成 in der → 关系 |
| wie | 关系性连接（先行词 Art/Weise） | **Die Art, wie er spricht, gefällt mir.** 他说话的方式我喜欢。 | 先行词是 Art/Weise → 关系性 |
| warum/weshalb | 关系性连接（先行词 Grund） | **Der Grund, warum er ging, ist unklar.** 他离开的原因不明。 | 先行词是 Grund → 关系性 |
| W + auch immer | 概括让步 | **Was auch immer du tust, mach es gut.** 无论你做什么，做好它。 | 表"无论" → 让步 |
| wann | **不能**作关系词 | ✗ *die Zeit, wann…* → ✓ die Zeit, **in der/als**… | 只用于疑问 |

## 4. 主句触发词/框架穷举（按语义场分类）

> 记忆原则：W-从句的主句谓词一定属于"**要一个信息空位来补全**"的语义场。

**A. 知识、信息获取**
wissen, nicht wissen, erfahren, herausfinden, herausbekommen, feststellen, ermitteln, klären, abklären（奥/瑞常用）, in Erfahrung bringen, prüfen, überprüfen, kontrollieren, untersuchen, recherchieren, nachsehen/nachschauen/nachlesen, sich informieren (über)
- **Ich weiß nicht, wo er wohnt.** 我不知道他住哪儿。
- **Die Polizei ermittelt, wer die Tat begangen hat.** 警方在调查是谁作案。
- **Wir müssen noch klären, wie das passieren konnte.** 我们还必须查清这是怎么发生的。

**B. 提问、求知**
fragen, sich fragen, nachfragen, sich erkundigen, wissen wollen, (gern) wissen möchten, darf ich fragen, könnten Sie mir sagen, rate mal
- **Er fragte mich, wann ich Zeit hätte.** 他问我什么时候有空。
- **Ich frage mich, wer das wohl war.** 我思忖那会是谁。
- **Rate mal, wer gerade angerufen hat！** 猜猜刚才谁打电话了！

**C. 告知、表达**
sagen, erzählen, berichten, mitteilen, schreiben, erklären, beschreiben, schildern, zeigen, verraten
- **Sag mir, wie du das gemacht hast.** 告诉我你是怎么做的。
- **Der Zeuge beschrieb, wie der Unfall passiert war.** 证人描述了事故是如何发生的。
- **Er verriet nicht, wo er den Schlüssel versteckt hatte.** 他没透露把钥匙藏哪儿了。

**D. 思考、决定、计划**
überlegen, sich überlegen, nachdenken (über), sich Gedanken machen (darüber), sich vorstellen (können), planen, besprechen, diskutieren, erwägen, abwägen, entscheiden, sich entscheiden
- **Wir überlegen noch, wohin wir fahren.** 我们还在考虑去哪儿。
- **Ich kann mir vorstellen, wie schwer das für dich war.** 我能想象这对你有多难。
- **Sie hat entschieden, was sie studieren will.** 她决定了要学什么。

**E. 记忆、遗忘**
sich erinnern, vergessen, sich merken, notieren, aufschreiben
- **Ich habe vergessen, wann der Termin ist.** 我忘了预约是什么时候。
- **Merk dir, wo du geparkt hast.** 记住你停哪儿了。

**F. 依赖、条件、评价框架**
abhängen (von): es hängt davon ab｜ankommen (auf): es kommt darauf an｜liegen (an): es liegt an…｜sich richten (nach)｜je nachdem｜wichtig, entscheidend, wesentlich, egal, gleichgültig, unklar, fraglich, offen, unsicher, umstritten, erstaunlich, überraschend, interessant, spannend, verdächtig, bezeichnend sein
- **Es hängt davon ab, wie viel Zeit wir haben.** 这取决于我们有多少时间。
- **Mir ist egal, wer das entscheidet.** 谁决定我无所谓。
- **Wichtig ist, wie man es sagt.** 重要的是怎么说。（≠ dass 从句强调"说的内容"）

**G. 情感、态度（常带介词关联词）**
gespannt (auf), neugierig (auf), stolz (auf), zufrieden (mit), sich freuen (über), sich ärgern (über), sich wundern (über), staunen (über), Angst haben (davor), sich Sorgen machen (darüber)
- **Ich bin gespannt (darauf), wie das ausgeht.** 我很期待结果如何。
- **Sie ärgert sich darüber, wie lange das dauert.** 她对这事拖这么久很恼火。

**H. 名词后的内容从句（同位性疑问从句）**
die Frage, das Problem, die Entscheidung, die Unsicherheit, das Rätsel, das Geheimnis, der Grund
- **Die Frage, wer die Kosten übernimmt, ist noch offen.** 谁承担费用的问题还没解决。
- **Das Problem, wie wir das finanzieren, muss gelöst werden.** 如何筹资的问题必须解决。

**I. 固定表达**
keine Ahnung haben, im Unklaren sein, Bescheid wissen, sich im Klaren sein, es sei dahingestellt, wer weiß
- **Ich habe keine Ahnung, wie das funktioniert.** 我完全不知道这怎么运作。
- **Wer weiß, wann wir uns wiedersehen.** 谁知道我们何时再见。（修辞性）

**J. 只接 dass/ob、不接 W-从句的谓词（必须记住，否则必错）**

| 谓词 | 只能 | 纠正示例 |
|---|---|---|
| glauben | dass | ✗ *Ich glaube, wann er kommt.* → ✓ **Ich glaube, dass er bald kommt.** 我相信他快来了。 |
| hoffen | dass | ✗ *Ich hoffe, wann er kommt.* → ✓ **Ich hoffe, dass er bald kommt.** |
| behaupten, meinen, finden | dass | ✗ *Er behauptet, wer das war.* → ✓ **Er behauptet, dass er es war.** |
| bedauern, fürchten | dass | ✗ *Ich bedauere, wie er geht.* → ✓ **Ich bedauere, dass er geht.** |
| bezweifeln | ob/dass | ✗ *Ich bezweifle, wer das schafft.* → ✓ **Ich bezweifle, ob er das schafft.** |
| bitten, auffordern, empfehlen | zu-Inf./dass | ✗ *Ich bitte ihn, wie er hilft.* → ✓ **Ich bitte ihn, mir zu helfen.** |
| denken（认为） | dass（"nachdenken über" 才能接 W） | ✗ *Ich denke, wie das geht.* → ✓ **Ich denke darüber nach, wie das geht.** |
| fragen | **ob/W，绝不 dass** | ✗ *Ich frage, dass er kommt.* → ✓ **Ich frage, ob/wann er kommt.** |

## 5. 使用场景清单（场合 → 框架 → 例句）

| 交际场景 | 典型框架 | 例句 |
|---|---|---|
| **转述别人的问题** | fragen + W/ob（可加 Konjunktiv I） | **Er fragte mich, wo ich gewesen sei.** 他问我刚才去哪儿了。 |
| **礼貌询问/请求** | Könnten Sie mir sagen…? Wissen Sie…? Darf ich fragen…? Ich würde gern wissen… | **Könnten Sie mir sagen, wann der nächste Zug fährt？** 您能告诉我下一班火车什么时候开吗？ |
| **表示不知道/不确定** | ich weiß nicht, keine Ahnung, ich bin mir nicht sicher | **Ich bin mir nicht sicher, ob das stimmt.** 我不确定这是否对。 |
| **好奇、惊讶、评价** | gespannt sein, staunen, es ist erstaunlich/interessant… | **Es ist erstaunlich, wie schnell er sich erholt hat.** 他恢复得这么快，令人惊讶。 |
| **决定、计划、讨论** | entscheiden, überlegen, besprechen, planen | **Wir müssen entscheiden, wohin wir fahren.** 我们必须决定去哪儿。 |
| **查明、调查、报告** | untersuchen, prüfen, feststellen, zeigen, ermitteln | **Die Studie zeigt, wie sich das Klima verändert.** 研究显示了气候如何变化。 |
| **记忆、遗忘** | sich merken, notieren, vergessen, sich erinnern | **Ich habe vergessen, wo ich geparkt habe.** 我忘了把车停哪儿了。 |
| **依赖、条件** | es hängt davon ab, es kommt darauf an, je nachdem | **Je nachdem, wie das Wetter wird, bleiben wir zu Hause.** 视天气而定，我们待在家。 |
| **无所谓** | es ist egal / spielt keine Rolle | **Es spielt keine Rolle, woher er kommt.** 他从哪儿来无关紧要。 |
| **名词后的"内容说明"** | die Frage / das Problem / die Entscheidung + W/ob | **Die Entscheidung, wer mitfährt, fällt morgen.** 谁同行，明天决定。 |
| **修辞、惯用** | Wer weiß…; es sei dahingestellt… | **Wer weiß, wie das endet.** 谁知道这会怎么收场。 |
| **请求、敦促** | Sag mir…! Erzähl mir…! Zeig mir…! | **Erzähl mir, was passiert ist！** 告诉我发生了什么！ |

**语用彩蛋**：**Weißt du, wie spät es ist？** 字面是询问时间，实际常是**责备**（"你看看都几点了"）。间接问句可作"礼貌外壳"，真正的请求藏在从句里——这是它区别于普通从句最重要的交际功能。

## 6. 与"普通从句"的总区别 + 判定流程

### 6.1 总对照表

| 维度 | W-疑问从句 | dass-从句 | ob-从句 | 关系从句 | 状语从句 |
|---|---|---|---|---|---|
| 从句内容 | 一个**待填变量**（谁/什么/哪种/何时/何地/为何/如何/多少） | 一个**完整命题** | 命题的**真值**（是/否） | 对**先行词**的说明/限定 | 时间/条件/原因/让步/目的/方式等**情形** |
| 引导词性质 | W-词：**本身是句子成分**，有格 | 纯连词（无句法角色） | 纯连词 | 关系代词：与先行词**性数一致** | 纯连词/连词性副词 |
| 有无先行词 | 无 | 无 | 无 | **有** | 无 |
| 句法功能 | 论元（主/宾/介宾/表语/同位） | 论元 | 论元 | 定语 | 状语（附加语） |
| 主句谓词限制 | 限"知识/信息/提问/依赖/评价"场 | 几乎所有命题态度动词 | 限"疑问/不确定"场 | 由名词决定 | 由事件关系决定 |
| 语序 | 尾语序 | 尾语序 | 尾语序 | 尾语序 | 尾语序 |
| 标点/语气 | 由主句决定，从句无问号 | 由主句决定 | 由主句决定 | — | — |

**要点**：语序（尾语序）**不是**区别标志——四类从句都是尾语序；区别在**引导词性质、有无先行词、从句内容、主句谓词要求**。

### 6.2 判定流程（教学"四问"）

1. **从句前面有没有一个名词/代词，从句是在补充说明它吗？**
   - 有 → **关系从句**，用 der/die/das（was/wo 有严格条件，见 §7.3）。
2. **没有先行词。从句能还原成一个直接问句吗？**
   - 能，且直接问句是 **是/否问句** → **ob**；
   - 能，且直接问句带 **W-词** → **W-疑问从句**（保留 W-词，改尾语序）。
3. **从句是"一个完整命题"、被当作事实转述/相信/希望吗？** → **dass**。
4. **从句表达"在什么时间/条件/原因/让步/目的/方式下"吗？** → **状语从句**（als, wenn, weil, obwohl, damit, indem…）；若是"无论谁/什么" → **W+auch immer**。

**三把检验钥匙**
- **先行词检验**：有先行词→关系；无→疑问。
- **还原检验**：能还原成直接问句→间接疑问；不能→关系/陈述。
- **替换检验**：W-词能被 **der/das/in dem** 替换→关系；不能替换→疑问。

## 7. 逐类精细辨析（含最小对立对与错误纠正）

### 7.1 与 dass-从句：**空缺 vs 完整命题**

| 对比 | 例句 | 含义 |
|---|---|---|
| dass | **Ich weiß, dass er in Wien war.** | 我知道他去过维也纳。（完整事实） |
| W | **Ich weiß, wo er war.** | 我知道他当时在哪儿。（信息槽：地点） |
| dass | **Sie hat gesagt, dass sie kommt.** | 她说她会来。 |
| W | **Sie hat gesagt, wann sie kommt.** | 她说了她什么时候来。 |
| dass | **Ich habe gehört, dass er krank ist.** | 我听说他病了。 |
| W | **Ich habe gehört, wer krank ist.** | 我听说谁病了。 |

**语义细节（进阶）**
- **wissen + dass**：断言命题为真。
- **wissen + W**：以"该问题有答案（相关事件/对象存在）"为前提。**Ich weiß nicht, wer angerufen hat.** 我不知道谁打来的——仍**预设"有人打来过"**；而 **Ich weiß nicht, ob jemand angerufen hat.** 不预设。
- **nicht wissen + dass** 不是"缺信息"，而是"对命题的怀疑/否认"：**Ich weiß nicht, dass er verheiratet ist.** ≈ 据我所知他没结婚。与 **Ich weiß nicht, wo er wohnt.**（缺信息）完全不同。

**错误纠正**
- ✗ *Ich habe gehört, was er krank ist.* → ✓ **…, dass er krank ist.**
- ✗ *Ich weiß nicht, dass er will.*（想表达"不知道他想要什么"）→ ✓ **…, was er will.**

### 7.2 与 ob-从句：**具体变量 vs 是/否**

| 直接问句类型 | 从句引导词 | 例 |
|---|---|---|
| Ja/Nein-Frage：Kommt er? | **ob** | Ich weiß nicht, **ob** er kommt. 我不知道他是否来。 |
| W-Frage：Wann kommt er? | **W** | Ich weiß nicht, **wann** er kommt. 我不知道他何时来。 |
| W-Frage：Wer kommt? | **W** | Ich weiß nicht, **wer** kommt. 我不知道谁来。 |

**要点**
- 主句谓词相同也不影响选择：决定因素是**直接问句是"是否"还是"具体信息"**。
- 可以并列：**Ich weiß nicht, ob und wann er kommt.** 我不知道他是否来、什么时候来。（习惯顺序 ob und wann）
- 都有：wissen, fragen, prüfen, sich erkundigen, unsicher sein, es hängt davon ab（W 表"如何/是否"，ob 表"是否"）。
- **fragen 不能接 dass**：✓ **Ich frage ihn, ob/wann er kommt.**

**错误纠正**
- ✗ *Ich weiß nicht, ob wer kommt.* → ✓ **…, ob jemand kommt.** / ✓ **…, wer kommt.**（二选一，不能叠加）
- ✗ *Ich weiß nicht, kommt er.* → ✓ **…, ob er kommt.**（V 1 嵌入式仅在极口语/方言中，标准语禁止）

### 7.3 与关系从句：**本讲最重要的区别**（"有先行词→关系代词；无先行词→疑问代词"）

#### （1）核心铁律

| 铁律 | 内容 |
|---|---|
| ① | **有先行词**（名词/代词），从句是"说明哪一个/什么样的" → **必须用关系代词 der/die/das**，绝不能用疑问代词 wer/was/welcher！ |
| ② | **无先行词**，且表达"未知答案" → **必须用疑问代词**，绝不能用 der/die/das！ |
| ③ | 关系代词要与**先行词**性、数一致，格由从句内功能决定；疑问代词的指称**不依赖主句任何名词**（welcher/was für ein 只与从句内名词一致）。 |
| ④ | 关系从句给**已知的人/物**补充信息或限定；疑问从句表达**知识空缺**。 |

#### （2）最小对立对（每对都展示"同词不同功能"）

| 关系从句（有先行词） | 间接疑问从句（无先行词） |
|---|---|
| **Kennen Sie den Mann, der dort steht？** 您认识站在那儿的那位男士吗？ | **Wissen Sie, wer dort steht？** 您知道站在那儿的是谁吗？ |
| **Das ist die Kollegin, die ich gestern gefragt habe.** 这就是我昨天问的那位女同事。 | **Ich weiß nicht, wen ich gestern gefragt habe.** 我不知道昨天问了谁。 |
| **Das Buch, das ich gekauft habe, ist spannend.** 我买的那本书很精彩。 | **Ich weiß nicht, welches Buch ich kaufen soll.** 我不知道该买哪本书。 |
| **Das ist der Freund, den ich eingeladen habe.** 这就是我邀请的那位朋友。 | **Ich habe vergessen, wen ich eingeladen habe.** 我忘了邀请了谁。 |
| **Ich mag das Auto, das er fährt.** 我喜欢他开的那辆车。 | **Ich weiß nicht, was für ein Auto er fährt.** 我不知道他开什么样的车。 |

#### （3）错误清单（错误→正确→原因）

| 错误 | 正确 | 原因 |
|---|---|---|
| ✗ *Der Mann, **wer** dort steht, ist mein Lehrer.* | ✓ **Der Mann, der dort steht, ist mein Lehrer.** | 有先行词 der Mann → 关系代词；疑问代词不能修饰名词。 |
| ✗ *Ich kenne den Mann, **wer** da steht.* | ✓ **Ich kenne den Mann, der da steht.** | 同上（kennen 只接名词宾语，不接疑问从句）。 |
| ✗ *Das ist die Frau, **wen** ich getroffen habe.* | ✓ **Das ist die Frau, die ich getroffen habe.** | 格由从句内功能决定：Frau 是 treffen 的第四格→die（阴性第四格）。 |
| ✗ *Ich weiß nicht, **der** dort steht.* | ✓ **Ich weiß nicht, wer dort steht.** | 无先行词且有未知变量→疑问代词。 |
| ✗ *Das Buch, **was** ich gekauft habe, …*（书面标准） | ✓ **Das Buch, das ich gekauft habe, …** | 关系 was 只用于先行词 alles/etwas/nichts/das Beste…或指代整句；确定中性名词用 das（口语可闻 was，非标准）。 |
| ✗ *Alles, **welches** du sagst, ist wahr.* | ✓ **Alles, was du sagst, ist wahr.** | 先行词 alles → 关系词用 was。 |
| ✗ *Der Kollege, **wo** neben mir sitzt, …* | ✓ **Der Kollege, der neben mir sitzt, …** | 关系 wo 只（口语）用于地点/时间名词，不能指人。 |
| ✗ *Die Stadt, **wo** ich wohne, …*（正式书面） | ✓ **Die Stadt, in der ich wohne, …** | 口语可用 wo，书面标准用 in der。 |

#### （4）关系词家族速查（避免把关系用法误认为疑问）

| 关系词 | 使用条件 | 例 |
|---|---|---|
| der/die/das | 默认、标准 | **Der Film, den wir sahen, war gut.** |
| welcher | 可替代 der，书面/生硬 | **Der Zeuge, welcher den Unfall sah, …** |
| wer | 自由关系（无先行词，=derjenige, der） | **Wer zu spät kommt, den bestraft das Leben.** 迟到者，生活会惩罚他。 |
| was | 先行词为 alles/etwas/nichts/das Beste 等，或指代整句 | **Das ist das Beste, was ich je gesehen habe.** 这是我见过最好的。 |
| wo | 口语替 in dem/der（地点/时间） | **Das Dorf, wo ich aufwuchs, …** |
| wohin/woher | 书面、少数地点先行词 | **Die Stadt, wohin er zieht, …**（更标准：in die er zieht） |
| wie | 先行词 Art/Weise | **Die Art, wie er redet, …** |
| warum/weshalb | 先行词 Grund | **Der Grund, warum er ging, …** |

#### （5）"自由关系"与"间接疑问"的终极分辨（同一形式、不同主句谓词）

- **Wer das behauptet, lügt.** 说这话的人在撒谎。（概括/自由关系：对"人"作陈述，可改写 derjenige, der…）
- **Wer das behauptet, ist unklar.** 是谁说的还不清楚。（间接疑问：对"问题"作陈述，=Es ist unklar, wer das behauptet.）
- **Was du sagst, stimmt.** 你说的对。（自由关系：=Das, was du sagst…）
- **Ich weiß nicht, was du sagen willst.** 我不知道你想说什么。（疑问：不能替换成 das）

#### （6）教学口诀（可直接给学生）

> **"有先行词，必用关系代词；无先行词，才谈疑问代词。"**
> **"能换成 der/das → 关系；不能换、且能还原成问句 → 疑问。"**

### 7.4 与状语从句：**论元 vs 状语**（wann / wenn / als 三大混点）

| 引导词 | 适用 | 例 |
|---|---|---|
| **wann** | 直接/间接问句、"时间"相关的疑问；**不能**引导时间状语从句（标准语） | **Ich weiß nicht, wann er kommt.** 我不知道他什么时候来。 |
| **wenn** | 条件"如果"；现在/未来的时间"每当/当……时" | **Wenn er kommt, sage ich es dir.** 如果他来，我就告诉你。 |
| **als** | 过去**一次性**事件"当……时" | **Als ich ankam, war er schon weg.** 我到的时候他已经走了。 |

**错误纠正**
- ✗ *Ich weiß nicht, **wenn** er kommt.* → ✓ **wann er kommt.**（南德/奥/瑞士口语中可听到 "wenn"，属非标准，书面语禁用）
- ✗ *Ich weiß nicht, **als** er kommt.* → ✓ **wann er kommt.**
- ✗ *Wo er früher gewohnt hat, ist heute ein Park.* 若指"他以前住的地方"且为地点状语关系 → ✓ **Wo er früher gewohnt hat/dort, wo er früher gewohnt hat, ist heute ein Park.** 他以前住的地方现在是个公园。（"dort, wo…"是地点关系/状语；本句作主语也可成立，靠语境判定）

**判断关键**：疑问从句是主句谓词的**论元**（缺了它句子不完整：wissen 缺宾语），状语从句是**附加说明**（去掉后句子仍完整）。

### 7.5 与间接引语（indirekte Rede / Konjunktiv I）

- 间接**陈述**：dass + Konjunktiv I，或不用 dass 的 V 2 结构：**Er sagte, er habe keine Zeit.** 他说他没时间。
- 间接**问句**：保留 W-词/ob + 尾语序；正式转述用 Konjunktiv I：**Er fragte, wer das gewesen sei.** 他问那是谁。（口语常说 …gewesen war）
- 注意：间接问句**不能**改成"V 2 无连接词"结构：✗ *Er fragte, wo war ich gewesen.* → ✓ **Er fragte, wo ich gewesen sei/war.**

### 7.6 与不定式从句（zu-Infinitiv）：**动作 vs 变量**

| 结构 | 例 | 含义 |
|---|---|---|
| zu-Inf. | **Ich habe vergessen, die Tür abzuschließen.** 我忘了锁门。 | 一个动作/命题 |
| W-从句 | **Ich habe vergessen, wo ich den Schlüssel hingelegt habe.** 我忘了把钥匙放哪儿了。 | 一个信息空位 |
| W-从句 | **Ich weiß nicht, was ich tun soll.** 我不知道该做什么。 | 变量（做什么） |
| ob-从句 | **Ich weiß nicht, ob ich es tun soll.** 我不知道是否该做。 | 真值 |

**规则**：缺"一个动作"且主语一致→zu-Inf.；缺"谁/什么/何时/如何……"→W-从句。

### 7.7 名词后：**内容从句（疑问） vs 关系从句**——同一名词两种可能

| 疑问内容从句（说明"问题/决定的内容"） | 关系从句（说明"这个名词本身"） |
|---|---|
| **Die Frage, wer die Kosten übernimmt, ist noch offen.** 谁承担费用的问题还没解决。 | **Die Frage, die er gestellt hat, war schwer.** 他提的那个问题很难。 |
| **Das Problem, wie wir das finanzieren, muss gelöst werden.** | **Das Problem, das wir haben, ist groß.** 我们有的那个问题很大。 |
| **Die Entscheidung, ob wir fahren, fällt heute.** 我们是否出发的决定今天作出。 | **Die Entscheidung, die er getroffen hat, war richtig.** 他做的那个决定是对的。 |

**测试**：从句说明"内容"（可还原为问句）→疑问从句；从句说明"是哪一个/什么样的"（可换 der/die/das）→关系从句。

## 8. 中文母语者高频错误 20 条（错误→正确→原因）

| # | 错误句 | 正确句 | 原因 |
|---|---|---|---|
| 1 | *Ich weiß nicht, wann **kommt der Zug**.* | **…, wann der Zug kommt.** | 从句必须尾语序，不能 V 2。 |
| 2 | *Ich weiß nicht, wann **kommt er an**.* | **…, wann er ankommt.** | 可分动词在从句中前缀合并、整体靠后。 |
| 3 | *Weißt du, wie **kann ich** das machen？* | **…, wie ich das machen kann？** | 情态动词靠后。 |
| 4 | *Ich weiß nicht, **wer** ich fragen soll.* | **…, wen ich fragen soll.** | 格由从句内功能决定（fragen 第四格）。 |
| 5 | *Ich weiß nicht, **wer** ich danken soll.* | **…, wem ich danken soll.** | danken 支配第三格。 |
| 6 | *Ich weiß nicht, **wem Auto** das ist.* | **…, wessen Auto das ist. / …wem das Auto gehört.** | "谁的"作定语用 wessen。 |
| 7 | *Der Mann, **wer** dort steht, ist mein Lehrer.* | **Der Mann, der dort steht, …** | 有先行词→关系代词。 |
| 8 | *Ich weiß nicht, **der** dort steht.* | **…, wer dort steht.** | 无先行词+未知变量→疑问代词。 |
| 9 | *Das ist die Kollegin, **wen** ich gefragt habe.* | **…, die ich gefragt habe.** | 关系代词的性数跟先行词（die），格由从句内功能决定（第四格=die）。 |
| 10 | *Das Buch, **was** ich gekauft habe, …（书面） | **…, das ich gekauft habe, …** | 关系 was 只限 alles/etwas/nichts/das Beste 等及整句指代。 |
| 11 | *Alles, **welches** du sagst, … | **Alles, was du sagst, …** | 先行词 alles→was。 |
| 12 | *Der Kollege, **wo** neben mir sitzt, … | **Der Kollege, der neben mir sitzt, …** | 关系 wo 不能指人（且属口语）。 |
| 13 | *Ich weiß nicht, **wenn** er kommt.* | **…, wann er kommt.** | wenn=条件/时间状语；wann=疑问。 |
| 14 | *Ich weiß nicht, **ob wer** kommt.* | **…, ob jemand kommt. / …, wer kommt.** | ob 与 W-词不能叠加。 |
| 15 | *Ich weiß nicht, **kommt er**.* | **…, ob er kommt.** | 是/否问句→ob+尾语序。 |
| 16 | *Ich weiß nicht, **was** er wartet **auf**.* | **…, worauf er wartet.** | 介词宾语：物→wo(r)+介词。 |
| 17 | *Ich weiß nicht, **was** er heißt.* | **…, wie er heißt.** | 名字用 wie；was 问含义（Was heißt das?）。 |
| 18 | *Ich weiß nicht, **wo** er fährt.* | **…, wohin er fährt.** | 方向用 wohin；wo 是静态地点。 |
| 19 | *Ich **weiß** deinen Bruder nicht. / *Ich **kenne** nicht, wer das ist.* | **Ich kenne deinen Bruder nicht. / Ich weiß nicht, wer das ist.** | kennen+名词；wissen+从句。 |
| 20 | *Ich weiß nicht, wann er kommt**?*** | **…, wann er kommt.**（句号） | 标点由主句决定，主句是陈述句。 |
| 21 | *Ich weiß nicht **es**, wo er wohnt.* | **Ich weiß nicht, wo er wohnt.** | W-从句直接作宾语，通常不带 es（口语 "Ich weiß es nicht, wo…" 属变体）。 |
| 22 | *Was für **ein** Bücher…* | **Was für Bücher…**（复数无 ein） | 复数只用 was für+名词。 |
| 23 | *Wo er wohnt, **ich weiß nicht**.* | **Wo er wohnt, weiß ich nicht.** | 从句前置时主句倒装（V 2）。 |
| 24 | *Ich denke, **wie** das geht.* | **Ich denke darüber nach, wie das geht.** | denken（认为）只接 dass；"思考怎么做"用 nachdenken über。 |

## 9. 进阶：语体、地区、语义与特殊情况

### 9.1 语体差异（书面 vs 口语）

| 现象 | 口语 | 书面标准 |
|---|---|---|
| 间接问句 V 2 | "Ich weiß nicht, wo **ist** er."（非标准，极口语） | "…, wo er **ist**." |
| 关联词 es | "Ich **weiß es nicht**, wann…"（口语强调） | "Ich weiß nicht, wann…" |
| 介词宾语 | "auf **was** wartest du？/ Ich weiß nicht, auf was…"（口语） | "**worauf**…" |
| 关系 was 代替 das | "Das Buch, **was**…"（口语普遍） | "…, **das**…" |
| 关系 wo 代替 in dem | "Die Stadt, **wo**…" | "…, **in der**…" |
| 关系 welcher | 几乎不用 | 法律/行政文体（生硬） |
| wessen | 少用，多说 "Wem gehört…?" | 可用 |

### 9.2 地区差异

- **南德、奥地利、瑞士**口语：用 **wenn** 代替间接问句的 **wann**（"Ich weiß nicht, wenn er kommt."）——地区口语，**书面语一律用 wann**。
- **瑞士**：关系词 **wo** 在书面语中接受度明显高于德国标准（"Die Firma, wo ich arbeite"）；对学习者考试写作仍建议 in der。
- **wo** 代替 **wohin**（"Wo gehst du？"）为普遍口语现象，标准语用 Wohin…? 或可接受的拆分式 "Wo gehst du **hin**?"。

### 9.3 语义预设与否定辖域

- **wissen + W** 预设"存在答案/事件"：**Ich weiß nicht, wer das war.** 预设"有人来过/发生过某事"。
- **wissen + dass** 直接断言命题：**Ich weiß, dass er kommt.**
- **否定位置改变意义**：
  - **Ich weiß nicht, wer das gemacht hat.** 我不知道是谁做的。
  - **Ich weiß, wer das nicht gemacht hat.** 我知道谁**没**做这事。
- **事实性问题**：**Ich frage nicht, ob er kommt, sondern wann.** 我问的不是他来不来，而是何时来。

### 9.4 礼貌、修辞与习语化

- 礼貌请求外壳：**Könnten Sie mir sagen, wo hier die Toilette ist？** 您能告诉我洗手间在哪儿吗？（从句仍尾语序，即使口语常听到 "…wo geht's hier…"，正式场合勿用）
- 责备：**Weißt du, wie spät es ist？**（言下之意：太晚了！）
- 修辞：**Wer weiß, wie das endet.** 谁知道这怎么收场。／**Was weiß ich！** 我哪知道！（口语）
- 名词化：**Das Wie und Warum ist oft wichtiger als das Was.** 怎么做和为什么做，往往比做什么更重要。（W-词大写名词化）
- 让步/概括：**Was auch immer du tust, mach es gut.** 无论你做什么，做好它。／**Wer auch immer anruft, ich bin nicht da.** 谁打电话来我都不在。
- 条件框架：**Je nachdem, wie das Wetter ist, fahren wir ans Meer.** 视天气而定，我们去海边。／**Je nachdem, ob er Zeit hat, …**

### 9.5 嵌套、被动与复杂结构

- 嵌套：**Ich weiß nicht, ob sie weiß, wo er wohnt.** 我不知道她是否知道他住哪儿。
- 被动主句（W-从句作主语，es 先行）：**Es wurde nicht geklärt, wie der Fehler entstanden ist.** 错误如何产生尚未查明。／**Es ist noch nicht entschieden, wer die Aufgabe übernimmt.** 谁接手这个任务还没定。
- Ersatzinfinitiv：**Ich weiß nicht, wie er das hätte machen sollen.** 我不知道他当时该怎么做。
- 多重疑问：**Er fragte, wer wem was gegeben habe.** 他问谁给了谁什么。

### 9.6 汉德对比总结（教学提示）

| 中文 | 德语要点 | 学生易错 |
|---|---|---|
| 我不知道他是谁 | 尾语序 + wer | *…, wer ist er* |
| 我不知道他叫什么 | **wie** er heißt（名字用 wie） | *was er heißt* |
| 我不知道他去哪儿 | **wohin**（方向） | *wo* |
| 我不知道他是否来 | **ob** | *wenn / dass* |
| 我认识那个人，他站在那儿 | 关系从句后置 + der | *…, wer dort steht* |
| 那个我认识的人 | 关系从句在名词后：Der Mann, den ich kenne | 中文"的"字前置结构迁移导致关系/疑问混淆 |
| 不知道（缺信息） | wissen + W/ob | kennen + 从句（✗） |
| 知道（认识）某人 | kennen + 名词 | wissen + 名词（✗） |

## 10. 一页速记（判定口诀）

1. **先问先行词**：有→关系代词 der/die/das（was/wo 有严格条件）；无→继续。
2. **再还原因问句**：是/否→ob；W-问句→W-词 + 尾语序。
3. **看谓词语义场**：知识/提问/告知/思考/记忆/依赖/评价→W/ob 可用；glauben/hoffen/behaupten 等→只能 dass。
4. **看内容是"变量"还是"命题"**：变量→W；命题→dass；情形→状语从句；"无论"→W+auch immer。
5. **铁律**：**"有先行词，必用关系代词；无先行词，才谈疑问代词。"**
