# 第一虚拟式转述对话、传闻和自述
这页讲的是德语 C 1 常见知识点：**用第一虚拟式 Konjunktiv I 转述对话、传闻和自述**。核心是：说话人不直接承担内容真实性，而是表示“这是别人说的/听来的/据称”。

**总结构**
德语转述常用：

```text
主句 + Konjunktiv I
```

或：

```text
情态动词的 Konjunktiv I + 动词不定式
```

例如：

```text
Er sagt, er sei krank.
他说他病了。
```

这里 `sei` 是 `sein` 的第一虚拟式，表示“据他说”，不是说话人亲自确认。

---

### **1. 对命令、请求、劝告的间接转述**

图片第一部分讲的是：如果原话是命令、请求、要求，转述时常用这些情态动词的第一虚拟式：

| 原意 | 转述常用词 | 语气 |
|---|---|---|
| 礼貌请求 | `mögen` | 请某人做某事 |
| 要求、劝告 | `sollen` | 应该做某事 |
| 命令、禁止 | `müssen / nicht dürfen / nicht sollen` | 必须、不得、不应该 |

结构是：

```text
主句 + 情态动词 Konjunktiv I + 动词不定式
```

例如：

```text
Er hat sie gebeten, sie möge bitte kommen.
他请求她来一下。
```

直译是：“他请求她，她愿意来一下。”  
实际意思就是：**他请她来。**

```text
Sie sagte ihm, er solle sie in Ruhe lassen.
她对他说，他应该让她安静。
= 她叫他别烦她。
```

```text
Er schrie den Hund an, er dürfe nicht bellen und müsse endlich leise sein.
他冲狗喊，说它不许叫，必须安静。
```

注意：

```text
dürfe nicht
```

表示“不允许”。

```text
müsse
```

表示“必须”。

`solle` 也可以用于命令式转述：

```text
Komm sofort!
→ Er sagte, ich solle sofort kommen.
他说我应该马上来。
```

### **2. 对传闻的转述：sollen + 不定式**

图片第二部分是重点：**sollen 可以表示“据说、听说、传闻中……”**

结构：

```text
主语 + soll/sollen + 不定式
```

这时 `sollen` 不再是普通的“应该”，而是表示**传闻**。

例如：

```text
Ich habe gelesen: Sänger X gibt keine Konzerte mehr.
→ Sänger X soll keine Konzerte mehr geben.
我读到：歌手 X 不再开演唱会了。
→ 据说歌手 X 不再开演唱会了。
```

这里 `soll ... geben` 不是“应该举办”，而是“据说有/据说开”。

再看过去时：

```text
Ich habe gehört: Schauspielerin X hat 10 kg abgenommen.
→ Schauspielerin X soll 10 kg abgenommen haben.
我听说女演员 X 瘦了 10 公斤。
```

结构是：

```text
soll + Partizip II + haben/sein
```

也就是：

```text
soll abgenommen haben
据说已经减重了
```

常见例子：

```text
Er soll sehr reich sein.
据说他很有钱。
```

```text
Sie soll früher in Berlin gewohnt haben.
据说她以前住在柏林。
```

```text
Der Film soll sehr gut sein.
听说这部电影很好。
```

这里说话人的态度通常是：**我只是转述，不保证真假。**

### **3. 对自我陈述的转述：wollen + 不定式**

图片第三部分讲的是：如果某人自己声称某事，可以用：

```text
wollen + 不定式
```

意思是：**某人自称…… / 声称自己……**

例如：

```text
Herr X sagt: Ich bin der Größte.
→ Herr X will der Größte sein.
X 先生说：我是最厉害的。
→ X 先生自称自己是最厉害的。
```

这里 `will` 不是普通的“想要”，而是“声称”。

再看过去：

```text
Herr Y sagt, er war als Erster im Ziel.
→ Herr Y will als Erster im Ziel gewesen sein.
Y 先生说自己第一个到达终点。
→ Y 先生声称自己是第一个到达终点的人。
```

过去结构：

```text
will + Partizip II + haben/sein
```

例如：

```text
Er will nichts gesehen haben.
他声称自己什么也没看见。
```

```text
Sie will den Brief nie bekommen haben.
她声称自己从没收到那封信。
```

```text
Er will das nie gesagt haben.
他声称自己从没说过那话。
```

这正是图片标题里的句子：

```text
Er will das nie gesagt haben.
```

意思不是“他想从没说过这话”，而是：

```text
他声称自己从没说过这话。
```

语气上往往带一点怀疑：他说是这么说，但我不一定信。

---

### **sollen 和 wollen 的区别**

这是这页最重要的区别：

```text
Er soll das gesagt haben.
据说他说过这话。
```

信息来源是别人、媒体、传闻。

```text
Er will das gesagt haben.
他自称说过这话。
```

信息来源是他本人。

再比较：

```text
Sie soll krank sein.
据说她病了。
```

```text
Sie will krank sein.
她声称自己病了。
```

第二句可能暗含怀疑：她说她病了，但我不一定相信。

---

### **现在与过去的结构**

现在或同时发生：

```text
sollen/wollen + Infinitiv
```

例如：

```text
Er soll reich sein.
据说他很富有。
```

```text
Er will reich sein.
他自称很富有。
```

过去发生：

```text
sollen/wollen + Partizip II + haben/sein
```

例如：

```text
Er soll das Buch gelesen haben.
据说他读过那本书。
```

```text
Er will das Buch gelesen haben.
他声称自己读过那本书。
```

如果动词用 `sein` 构成完成时：

```text
Sie soll nach Wien gefahren sein.
据说她去了维也纳。
```

```text
Sie will nach Wien gefahren sein.
她声称自己去了维也纳。
```

---

### **和普通 Konjunktiv I 的关系**

普通间接引语也可以这样说：

```text
Er sagt, er habe das nie gesagt.
他说他从没说过这话。
```

但用 `wollen` 时语气更明确：

```text
Er will das nie gesagt haben.
他声称自己从没说过这话。
```

区别是：

```text
Er sagt, er habe ...
```

中性转述。

```text
Er will ... haben.
```

强调“这是他自己的说法”，常带怀疑或距离感。

### **常见第一虚拟式形式**

这页出现的几个形式要记住：

| 原形 | Konjunktiv I |
|---|---|
| sein | sei |
| haben | habe |
| werden | werde |
| können | könne |
| müssen | müsse |
| dürfen | dürfe |
| sollen | solle |
| mögen | möge |
| wollen | wolle |

第三人称最常用：

```text
er sei
er habe
er könne
er müsse
er dürfe
er solle
er möge
```

但在 `sollen/wollen + 不定式` 表传闻/自称时，常用正常变位：

```text
er soll
sie soll
sie sollen
er will
sie will
sie wollen
```

例如：

```text
Er soll krank sein.
据说他病了。
```

```text
Er will krank sein.
他自称病了。
```

---

### **一句话总结**

这页可以这样记：

```text
sollen = 据说、听说、传闻
wollen = 自称、声称自己
mögen/solle/müsse/dürfe = 转述请求、要求、命令、禁止
```

重点句型：

```text
Er soll das gesagt haben.
据说他说过这话。

Er will das gesagt haben.
他声称自己说过这话。

Er will das nie gesagt haben.
他声称自己从没说过这话。
```
