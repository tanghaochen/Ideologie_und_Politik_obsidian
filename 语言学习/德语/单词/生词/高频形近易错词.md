# 高频形近易错词

这里为你整理了德语中非常容易混淆的形近/音近词。根据你的需求，主要按照**拼写结构**和**发音特征**进行了简单分类，方便你直接作为词汇导航使用。

### 1. 包含 -eiter / -ieder / -etter 的核心易混词（你的举例及延伸）

^o2icec

^aeqobl

- **wieder**：又，再（副词）
- **wider**：反对，逆向（介词/前缀，发音与 wieder 完全相同）
- **weiter**：更远的，继续（weit 的比较级）
- **Wetter**：天气（名词）
- **breiter**：更宽的（breit 的比较级，你提到的 breter 应该是这个）
- **Bretter**：木板（名词 Brett 的复数）
- **Bieter**：出价者，投标人（名词）
- **bitter**：苦的（形容词）
- **heiter**：晴朗的，开朗的（形容词）
- **Leiter**：领导者（阳性名词） / 梯子（阴性名词）

### 2. 经典 B-T 组合动词（最容易记错元音）

- **bieten**：提供，出价
- **bitten**：请求
- **beten**：祈祷
- **betten**：铺床

### 3. “ie” 与 “ei” 字母颠倒（发音完全不同：ie 发“依”，ei 发“哎”）

- **Wein**：葡萄酒
- **Wien**：维也纳（地名）
- **Lied**：歌曲
- **Leid**：痛苦，悲哀
- **sie**：她 / 他们
- **sei**：是（sein 的虚拟式）
- **schreiben**：写（动词原形）
- **schrieben**：写（过去式）

### 4. 常见的双写/单写辅音易混词

^d5xfqd

^32antb

- **Staat**：国家
- **Stadt**：城市
- **statt**：代替（介词）
- **fiel**：落下（fallen 的过去式）
- **viel**：很多
- **Wesen**：本质，生物
- **wissen**：知道

### 5. 变音（Umlaut）易混词对

- **schon**：已经
- **schön**：美丽的
- **fordern**：要求，索取
- **fördern**：促进，资助
- **drucken**：打印，印刷
- **drücken**：按，压
- **zahlen**：支付，付款
- **zählen**：数数，计算

### 6. 发音相近的其他高频短词

- **Meer**：海洋
- **mehr**：更多
- **Leere**：空虚
- **Lehre**：教导，学徒期
- **Wand**：墙壁（内墙）
- **Wind**：风
