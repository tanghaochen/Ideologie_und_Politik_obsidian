## 二、错在哪（按病根归类，不按题）

### 1. 完成时没有第二分词这个概念（重灾区）

两处错误一模一样：

| 你写的 | 应该是 |
|---|---|
| `bin ich aufwachen` | `bin ich aufgewacht` |
| `habe ich aufstehen` | `bin ich aufgestanden` |
| `bin ich einschlafen`（改错题原句，你没看出来） | `bin ich eingeschlafen` |

外加助动词：`aufstehen / aufwachen / einschlafen` 是状态变化 → **sein**，不是 haben。唯一对的完成时是那道纯助动词改错（`bin nach Wien gefahren` / `habe einen Kurs gemacht`）。

**正确写法**：`Gestern Morgen bin ich schon um sechs Uhr aufgewacht, aber ich bin erst um sieben Uhr aufgestanden.`

### 2. 介词是动词带来的，你又把它省了

- `teilnehmen`：写成 `einer Schreibkurs`，介词 an 直接没了，格也当成第四格。应为 `an einem Schreibkurs`。
- `investieren in + Akkusativ`：改错题只改对了 `dich → dir`，`in neuen Maschinen` 没动。应为 `in neue Maschinen`（方向 = 第四格）。

### 3. 名词和固定短语还停在"逐词翻译"

| 你写的 | 应该是 | 说明 |
|---|---|---|
| `nächste Moment` | `nächsten Monat` | Moment 是"片刻"，不是月份；der Monat 阳性 |
| `nach der Arbeitplatz` | `zur Arbeit` | 去上班是 zur Arbeit gehen；Arbeitsplatz 是"工位" |
| `ganz Tag Kranke` | `den ganzen Tag Fieber` | den ganzen Tag（阳性第四格）；Fieber haben 不带冠词 |
| `Dies Packet` | `Dieses Paket` | das Paket 中性；拼写 Paket |

### 4. 拼写与大小写

`Haute` → heute｜`nachmittage` → Nachmittag｜`comme` → kommen｜`seben` → sieben｜`Arbeitplatz` → Arbeitsplatz｜`Packet` → Paket。

德语名词一律大写、复合词不拆音，这两条能消掉这里大半的错。

### 5. 改错题的两个操作失误

- 只改一半：`investieren` 那处漏了（题目写了"共两处"）。
- 把对的改成错的：`Gestern habe ich gesprochen` 本来就成立，你把 `habe` 改成 `hatte`。改错题的第一问永远是"这句到底错没错"。

### 6. Konjunktiv II 还是一片空白

Cloze 两个空只写了一个 `ist`。`Könnten Sie …?` 和 `Das wäre nett.` 这两个块，投诉信/邮件里每次都用得上，属于必须背下来的死块。
