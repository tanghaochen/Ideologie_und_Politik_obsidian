## 一、三个真病根（按严重程度）

### 1. 可分动词的第二分词没写出来 —— 连续两晚，全批次最重

- 错法：`aufäumen`（不定式加错变音）、`rufe … an` 顶替 `angerufen`、`aufwacht` 该改没改、`einschlage` 自造形式。
- 正确写法：第二分词把 `-ge-` 夹在前缀和词干之间 —— **auf + ge + räumt = aufgeräumt**，**an + ge + rufen = angerufen**。
- 下次怎么练：只有一个动作。遇到可分动词的完成时，先写出前缀，再写 `ge`，再写词干，最后加 `-t/-en`。不要整词凭记忆拼。

### 2. 动词决定的格：看见"人"就默认第四格

- 错法：`meinen Kollegen gedankt`（danken + D）、`meinen Nachbarn geholfen`（helfen + D）、`meinen Bruder` 代替 `meinem Bruder`（gehören + D）。
- 正确写法：阳性第三格词尾一律 **-em** → `meinem Kollegen` / `meinem Nachbarn` / `meinem Bruder`。
- 下次怎么练：danken / helfen / gratulieren / folgen / antworten / gehören / passen / gefallen 这组背成"第三格动词表"，做题时先查表再写。

### 3. 动词固定介词漏写或选错 —— 三题全错，同一处连错

- 错法：`eine Besprechung teilnehmen`（漏 `an`，两晚都漏）、`mit dem Vermieter beschwerten`（该用 `bei`，且 `über` 整个缺失）、`im öffentlichen Verkehr investieren`（该用方向格 `in + A`）。
- 正确写法：`an einer Besprechung teilnehmen`（an + D）、`sich bei dem Vermieter über den Lärm beschweren`（bei + D / über + A）、`Geld in den öffentlichen Verkehr investieren`（in + A，方向）。
- 下次怎么练：动词和它的介词当成一个词背（teilnehmen-an、beschweren-bei/über、investieren-in），不要分开记。
